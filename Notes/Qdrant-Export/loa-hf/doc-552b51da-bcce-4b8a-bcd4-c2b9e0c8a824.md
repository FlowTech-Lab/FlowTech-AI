League of Angels Heaven Fury - THUNDER Set Equipment Base Stats: THUNDER set equipment pieces provide consistent base stat bonuses. Each THUNDER Grade 15 equipment piece (Primary weapon, and when upgraded: Secondary weapon, Necklace, Pendant, Left Ring, Right Ring) provides base stats: Attack +21875, Penetration +10938. These are the base equipment stats before enhancement bonuses. THUNDER set pieces have higher base stats than GALE set pieces. When GALE equipment is upgraded to THUNDER, it will gain these higher base stats. Character Lilith's primary weapon (THUNDER) has these base stats. Secondary weapon and accessories (currently GALE) will have these stats when upgraded to THUNDER Grade 15.
