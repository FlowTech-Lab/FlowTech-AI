League of Angels Heaven Fury - Set Names Clarification: GALE set is the same as Tempête set (Storm set). GALE is the French name for Tempête/Storm. THUNDER set is Tonnerre set. Both GALE/Tempête and THUNDER/Tonnerre are different sets. GALE/Tempête set provides balanced or defensive stats. THUNDER/Tonnerre set provides higher offensive base stats. Character Lilith has equipment in both GALE/Tempête and THUNDER/Tonnerre sets. When documentation refers to "Tempête" or "Storm", it means GALE set. When documentation refers to "Tonnerre" or "Thunder", it means THUNDER set.
