League of Angels Heaven Fury - Equipment Set GALE: GALE set (Wind set) provides set bonuses when multiple pieces are equipped. Character Lilith has GALE Grade 15 pieces (Shield, Chest, Leggings, Boots, Rings, Accessory) and GALE Grade 14 pieces (Shoulders, Gloves, Accessory). GALE set typically provides balanced stats or defensive/utility bonuses. Set bonuses activate at 2-piece, 4-piece, and 6-piece thresholds. Having multiple GALE pieces provides significant set bonuses. Mixing Grade 14 and 15 GALE pieces maintains set bonuses with different stat values.
