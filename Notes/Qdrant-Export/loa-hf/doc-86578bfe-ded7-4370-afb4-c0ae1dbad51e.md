League of Angels Heaven Fury - GALE Set Equipment Stats: GALE set equipment pieces provide consistent stat bonuses. Each GALE equipment piece (Secondary weapon, Necklace, Pendant, Left Ring, Right Ring) provides: Attack +14583, Penetration +7292. These stats are base equipment stats that contribute to total character stats. GALE set pieces work together to provide set bonuses when multiple pieces are equipped. Character Lilith has multiple GALE Grade 15 pieces with these stats contributing to total combat power.
