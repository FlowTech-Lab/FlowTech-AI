Diagnostic et Solution - Problème de Dossiers Récursifs dans Obsidian/Templater

PROBLÈME:
Création récursive de dossiers causée par interaction Templater + Folder Templates mal configurée. Boucle infinie quand script crée fichiers dans dossier surveillé.

CAUSE RACINE:
- trigger_on_file_creation: true + Folder Templates = récursion
- Conflit templates (ex: 60-Infrastructure + 60-Infrastructure/Service-Inventory)
- Script Templater créant fichiers dans dossiers surveillés

SOLUTIONS:
1. Désactiver temporairement trigger_on_file_creation pour tester
2. Ordre Folder Templates: spécifiques au-dessus, génériques en dessous
3. Supprimer conflits templates (1 template par dossier max)
4. Vérifier scripts Templater créant fichiers
5. Utiliser File Regex Templates au lieu de Folder Templates si besoin

CHECKLIST DIAGNOSTIC:
1. Arrêter Obsidian
2. Backup data.json
3. Valider JSON (jsonlint.com ou jq)
4. Corriger config (désactiver trigger ou supprimer conflit)
5. Redémarrer et tester
6. Developer Console (Ctrl+Shift+I) pour logs

FICHIERS:
- .obsidian/plugins/templater-obsidian/data.json (config principale)
- .obsidian/plugins/templater-obsidian/data.json.backup (backup avant modif)

DOCUMENTATION:
- GitHub Issue #927 (problème identique)
- SilentVoid13.github.io/Templater/settings.html

CONFIGURATION VAULT FLOWTECH:
trigger_on_file_creation: true
enable_folder_templates: true
Conflit détecté: 60-Infrastructure (2 templates)

ACTION IMMÉDIATE:
1. Vérifier data.json
2. Supprimer conflit 60-Infrastructure
3. Tester création nouveau fichier
4. Consulter Developer Console si pb persiste
