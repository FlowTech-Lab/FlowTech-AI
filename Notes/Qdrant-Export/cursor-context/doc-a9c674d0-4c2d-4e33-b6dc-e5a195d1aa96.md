Rails Memo - Fiche mémo Rails complète

## Rails - Fiche Mémo

### Création d'une App Rails
```bash
# Créer une nouvelle app
bin/rails new mon_app

# Démarrer le serveur (avec port et binding)
bin/rails server -p 3000 -b 0.0.0.0

# Ouvrir la console
bin/rails console
```

### Créer un Modèle
```bash
# Générer un modèle avec attributs
bin/rails generate model Resource name:string published_on:date status:integer

# Passer la migration
bin/rails db:migrate

# Vérifier le statut
bin/rails db:migrate:status
```

### Console Rails - Manipulation
#### Créer des objets
```ruby
# Méthode 1 : new + save! (avec erreurs)
resource = Resource.new
resource.name = "Mon Article"
resource.published_on = Date.today
resource.status = :published
resource.save!

# Méthode 2 : create! direct (avec erreurs)
Resource.create!(name: "Mon Article", published_on: Date.today, status: :published)
```

#### Requêtes de base
```ruby
# Voir tous les objets
Resource.all

# Trouver par ID
Resource.find(1)

# Trouver par attribut
Resource.find_by(name: "Mon Article")

# Compter
Resource.count

# Première/dernière
Resource.first
Resource.last
```
