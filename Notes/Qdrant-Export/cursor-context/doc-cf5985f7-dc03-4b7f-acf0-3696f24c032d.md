Guide Navbar Grenoble Roller - Design et UX pour barre de navigation

## Guide Navbar Grenoble Roller

### Éléments nécessaires dans la navbar
- **Accueil** : Retour à la page d'accueil
- **Événements / Agenda** : Accès à tous les événements à venir
- **Créer un événement** : Mise en avant pour contribuer
- **Communauté / Membres** : (Optionnel) Liste des membres
- **Ressources / Entraînements / Parcours** : (Optionnel) Infos pratiques et contenus spécifiques
- **Statistiques / Résultats** : (Optionnel) Scores/stats sorties
- **Contact / À propos** : Infos plateforme

### Menu utilisateur (profil/déconnexion)
Dans le coin supérieur droit, préférer une icône profil/avatar :
- **Mon profil** : Paramètres et infos utilisateur
- **Mes événements** : Historique des participations
- **Déconnexion** : Libellé clair et séparé visuellement
- **Aide/Support** (optionnel)

### Conseils UX/UI
- Actions principales à gauche, actions utilisateur à droite
- Libellés simples et explicites
- Hamburger menu sur mobile, dropdown sur desktop
- Grouper logiquement les accès
- Icônes pour identification rapide

### Exemple d'arborescence
| Navbar principal | Dropdown | Action / Section |
|------------------|----------|------------------|
| Accueil | - | / |
| Événements | - | /evenements |
| Créer un événement | - | /evenement/nouveau |
| Ressources | Parcours, Initiations | /ressources/parcours, /ressources/initiations |
| Mon profil (avatar/icône) | Mes événements, Profil, Déconnexion | /profil, /profil/evenements, /logout |
