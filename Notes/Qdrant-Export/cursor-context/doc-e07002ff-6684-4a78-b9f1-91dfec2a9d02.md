PERPLEXITY INSIGHTS ANALYSIS - METADATA ARCHITECTURE REINFORCEMENT

=== KEY INSIGHTS FROM PERPLEXITY ===
1. METADATA IS CRITICAL FOR PRODUCTION SCALE
- At 50K files/day: pure vector search returns 30K results (3% of 1M vectors)
- Metadata filtering reduces search space from 30K to 50 results
- HNSW index optimization requires payload indexing for performance

2. MCP QDRANT CONTEXT LIMITATION CONFIRMED
- Metadata parameter serialization bug is Cursor MCP limitation, not Qdrant
- Workaround: structured text in information parameter
- PostgreSQL should handle complex metadata as source of truth

3. HYBRID ARCHITECTURE RECOMMENDED
- PostgreSQL: Business metadata, complex queries, audit trails
- Qdrant Payload: Vector search filtering (knowledge base only)
- Redis: LRU cache (TTL 24h) for frequent queries
- MCP Context: Text-only storage (workaround for serialization)

4. PRODUCTION SCALABILITY PATTERNS
- Payload indexes: agent_id (integer), file_hash (keyword), status (keyword)
- Filter cardinality: >5% use Filterable HNSW, <5% use Payload Index
- Hybrid search: PostgreSQL filter → Qdrant semantic search → Redis cache
