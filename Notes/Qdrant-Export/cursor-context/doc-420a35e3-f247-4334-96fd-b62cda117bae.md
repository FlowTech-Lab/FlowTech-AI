FlowTech-AI MCP Integration for Cursor IDE:
- Two MCP servers: mcp-qdrant (port 8000) and mcp-qdrant-knowledge (port 8001)
- Collection strategy: cursor-context (read-write for code) and cursor-knowledge (read-only for notes)
- Embedding model: BAAI/bge-large-en-v1.5 via FastEmbed (1024 dimensions)
- Setup: Copy cursor-mcp-config.json to ~/.cursor/mcp.json and edit server IP
- Test commands: @qdrant store "text" and @qdrant find query
- Notes sync: ./scripts/sync-notes.sh for initial sync, ./scripts/install-cron.sh for hourly auto-sync
- MCP context language: ALWAYS store in English for optimal embedding quality
- Named vectors required in Qdrant collections for MCP compatibility
