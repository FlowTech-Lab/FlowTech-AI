MCP Memory Agent - Purge Sécurisée et Promotion Automatique

## MCP Memory Agent - Purge Sécurisée et Promotion Automatique

### Objectif
Déléguer à un agent MCP la capacité de supprimer des vecteurs et piloter la purge mémoire en toute sécurité

### Vue d'Ensemble

#### Problème Résolu
- **Purge manuelle** : Fastidieuse et oubliée
- **Performance Qdrant** : Dégradation progressive sans cleanup
- **Promotion patterns** : Zéro automatisation
- **Sécurité** : Risque de suppression accidentelle

#### Solution
**Agent MCP dédié** avec permissions restreintes pour :
- ✅ Purge automatique des vecteurs expirés
- ✅ Promotion intelligente vers cursor-knowledge
- ✅ Soft-delete réversible 7 jours
- ✅ Alertes Discord/Slack

### Sécurité et Permissions

#### 1. Rôle Dédié Memory Manager

```yaml
# qdrant-acl.yaml
roles:
  memory_manager:
    permissions:
      - "qdrant:delete:expired"
      - "qdrant:promote:context_to_knowledge"
      - "qdrant:soft_delete:7_days"
      - "qdrant:read:metadata"
    restrictions:
      - "no:delete:knowledge_collection"
      - "no:delete:pinned_vectors"
      - "no:delete:recent_vectors"
```
