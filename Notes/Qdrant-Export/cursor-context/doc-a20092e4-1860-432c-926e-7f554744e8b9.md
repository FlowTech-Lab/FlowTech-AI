52Pi Mini Tower Kit V2 - OLED Compact Multi-Info Display (Oct 26, 2025). New display script: /usr/local/minitower/oled_compact.py (replaces sys_histogram.py). Layout: Line 1 shows CPU%, RAM%, TEMP in compact format. Line 2 shows IP address. Lines 3-4 show 4 core load bars (2x2 grid: C1 C2 on line 3, C3 C4 on line 4). Line 5 shows Fan PWM%, temperature, and RAM bar. Refresh rate: 2 seconds. Data sources: psutil for CPU/RAM, vcgencmd for temperature, telemetry log for fan PWM, socket for IP address. Service: minitower_oled.service active. All information visible at once in compact 128x64 display.
