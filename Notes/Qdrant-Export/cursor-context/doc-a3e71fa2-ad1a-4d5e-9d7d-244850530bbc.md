- **IP** : 192.168.0.245
- **VM ID** : 245
- **Type** : Firmware d'imprimante 3D
- **Status** : Actif

### Configuration
- **Rôle** : Firmware avancé pour imprimante 3D
- **Interface** : Mainsail ou Fluidd (WebUI)
- **MCU** : Communication avec carte mère imprimante

### Fonctionnalités
- **Firmware avancé** : Contrôle haute performance
- **Mesh bed leveling** : Calibration automatique du plateau
- **Input shaping** : Réduction des vibrations
- **Macros** : Automation des processus d'impression

### Interface Web

- **Précision** : Contrôle très fin des mouvements
