FlowTech-AI Docker Compose Service Dependencies:
- postgres: Base service with health check (pg_isready)
- redis: Base service with health check (redis-cli ping)
- minio: Base service with health check (curl /minio/health/live)
- clickhouse: Base service with health check (wget /ping)
- qdrant: Base service, no health check
- langfuse-worker: Depends on postgres, redis, minio, clickhouse (all healthy)
- langfuse-web: Depends on postgres, redis, clickhouse (healthy) + langfuse-worker (started)
- n8n: Depends on postgres (healthy) + qdrant (started)
- openwebui: Depends on qdrant (started)
- mcp-qdrant: Depends on qdrant (started)
- mcp-qdrant-knowledge: Depends on qdrant (started)
- searxng: No dependencies
- samba: No dependencies, uses host network mode
