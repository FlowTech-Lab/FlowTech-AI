Penpot - Création d'une Navbar Fonctionnelle, Étape 2 Navbar Complète. Conteneur principal : créer un board ou groupe pour la navbar, appliquer layout Flex horizontal, distribuer les éléments avec gap uniforme. Assemblage des éléments : faire glisser plusieurs instances du NavItem, personnaliser chaque instance (texte et icône différents), utiliser la fonction de swap de composants pour changer les icônes. Composant navbar final : sélectionner la navbar complète, créer un composant Navbar, organiser dans la bibliothèque d'assets.
