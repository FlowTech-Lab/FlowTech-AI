### Architecture Hybride Production

#### Pipeline 6 Agents N8N Optimisé
| Agent | Rôle | Métadonnées | Storage |
|-------|------|-------------|---------|
| **Agent 1** | Validation | PostgreSQL tracking | `vector_metadata` |
| **Agent 2** | Chunking | File hash dedup | `file_hash` |
| **Agent 3** | Embedding | Confidence score | `confidence_score` |
| **Agent 4** | Indexing | Qdrant payload | Payload indexes |
| **Agent 5** | RAG | Hybrid search | PostgreSQL + Qdrant |
| **Agent 6** | Monitoring | Performance metrics | ClickHouse |

#### Table PostgreSQL Critique
```sql
CREATE TABLE vector_metadata (
  id UUID PRIMARY KEY,
  collection_name TEXT,      -- cursor-context, cursor-knowledge
  agent_id INT,              -- 1-6 (validation → RAG)
  file_path TEXT,            -- Nextcloud path
  file_hash VARCHAR(64),     -- Pour dedup
  chunk_index INT,
  chunk_total INT,
  processing_time_ms INT,
  status VARCHAR(20),        -- pending, processing, completed, failed
  confidence_score FLOAT,
  timestamp TIMESTAMP
);
```
