Penpot - Fonctionnalités Interactives Prototypage. Prototypage Basique pour rendre navbar fonctionnelle : Mode Prototype (activer l'onglet Prototype), Interactions (sélectionner chaque élément de navigation), Connexions (faire glisser vers les boards de destination), Triggers (On Click pour navigation), Actions (Navigate To vers la page appropriée). États Interactifs Avancés : effets de survol (créer des boards pour chaque état Default, Hover, Active), utiliser Mouse Enter et Mouse Leave avec overlays, animations de transition (200ms recommandé). Limitations actuelles : pas d'états persistants natifs dans les composants, nécessite l'utilisation d'overlays pour les interactions complexes.
