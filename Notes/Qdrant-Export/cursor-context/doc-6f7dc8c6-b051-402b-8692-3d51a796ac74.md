Penpot - Système de Bibliothèques et Organisation des Assets. Structure recommandée : Components/Navigation (Navbar/Desktop, Navbar/Mobile, NavItem/Default, NavItem/Active), Buttons, Forms. Bibliothèques Partagées : Publication (Panneau Libraries → Publish), Import (télécharger fichier .penpot → Import dans équipe), Connexion (Assets → Libraries → + pour connecter), Synchronisation (mises à jour automatiques cross-projets). Nommage des Composants convention recommandée : [Element]/[Property1]/[Property2]/[Property3]. Exemple : Button/Size-Large/State-Primary/Theme-Dark.
