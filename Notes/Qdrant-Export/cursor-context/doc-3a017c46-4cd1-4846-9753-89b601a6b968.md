Structure Ops avec Watchdog - Configuration Production et Staging

Configuration Production (/ops/production/docker-compose.watchdog.yml):
- Watchtower avec poll interval 300s, cleanup activé, log level info
- Variables d'environnement via .env.watchdog.prod
- Volumes: docker.sock, scripts, config, logs production
- Fluent-bit pour logs centralisés
- Réseau externe app-network

Configuration Staging (/ops/staging/docker-compose.watchdog.yml):
- Watchtower avec poll interval 60s (plus fréquent), cleanup désactivé, log level debug
- Variables d'environnement via .env.watchdog.staging
- Volumes: docker.sock, scripts, config, logs staging
- Réseau externe app-network

Variables Production (.env.watchdog.prod):
- WATCHTOWER_REGISTRY credentials
- Notifications Slack
- Rollback settings: ROLLBACK_ON_FAILURE=true, BACKUP_BEFORE_UPDATE=true, HEALTH_CHECK_TIMEOUT=60
