Structure Ops avec Watchdog - Dockerfile Partagé et Scripts Opérationnels

Dockerfile Watchdog Partagé (/ops/shared/Dockerfile.watchdog):
- Base: containrrr/watchtower:latest
- Scripts backup/rollback dans /app/scripts
- Logs dans /app/logs
- Entrypoint watchtower avec cleanup et interval 300

Scripts Opérationnels:

rollback.sh: Script de rollback production qui récupère la dernière version stable, arrête les containers, pull l'image, redémarre et vérifie le health check. Logs dans /app/logs/rollback-*.log

backup.sh: Script de backup avant mise à jour qui sauvegarde docker-compose config et volumes dans /app/backups avec timestamp. Crée backup_*.tar.gz et compose_*.yml

health-check.sh: Script de vérification santé qui teste l'endpoint /health avec 5 tentatives max, 5 secondes entre chaque. Retourne 0 si succès, 1 si échec après toutes les tentatives.
