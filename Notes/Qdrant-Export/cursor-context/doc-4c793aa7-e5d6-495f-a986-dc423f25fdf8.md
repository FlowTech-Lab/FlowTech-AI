Penpot - Layouts Réactifs et Design Tokens. Flex Layout pour navigations horizontales : Direction Row, Wrap No-wrap généralement, Justify Space-between ou Space-around, Align Center. Grid Layout pour structures complexes : colonnes définies en fr (fractions), positionnement manuel des éléments, support du responsive design. Design Tokens Intégrés workflow recommandé : 1) Créer tokens de couleurs/espacements, 2) Appliquer aux composants via le panneau Tokens, 3) Organiser en Sets thématiques (Light/Dark), 4) Synchroniser avec équipe via bibliothèques partagées.
