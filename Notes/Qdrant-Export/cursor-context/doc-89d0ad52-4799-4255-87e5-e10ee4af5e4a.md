RSpec Testing Best Practices for Rails 8 with Devise and ActiveJob:

AUTHENTICATION IN REQUEST SPECS:
- Problem: sign_in helper from Devise::Test::IntegrationHelpers can fail with "Could not find a valid mapping for #<User>"
- Solution: Use post user_session_path instead of sign_in in request specs
- Pattern: post user_session_path, params: { user: { email: user.email, password: 'password123' } }
- Configuration: Include Devise::Test::IntegrationHelpers in rails_helper.rb for type: :request
- Difference: Request specs use post user_session_path, System specs use login_as(user) helper, Controller specs use sign_in user

ACTIVEJOB / ACTIONMAILER TESTING:
- Problem: deliver_later enqueues emails in ActiveJob, not sent immediately in tests
- Solution: Include ActiveJob::TestHelper and use perform_enqueued_jobs block
- Pattern: perform_enqueued_jobs do ... expect ... end
- Mailer tests: Check decoded body (html_part.decoded) instead of body.encoded for multipart emails
- Date testing: Check for year and digits instead of exact format (locale variations)
- Price testing: Check for amount presence instead of exact format (10,00 vs 10.00)

FACTORYBOT BEST PRACTICES:
- Always define date traits (:upcoming, :past) in factories
- Use traits instead of manually specifying values
- Pattern: create(:event, :published, :upcoming) not create(:event, :published, start_at: 1.week.from_now)
- Define reusable traits for common cases (:with_limit, :unlimited)

COMMON ISSUES AND FIXES:
- Syntax errors in controllers: Use double quotes for strings with apostrophes
- Date format failures: Check for year and digits, not exact format
- Price format failures: Check for amount presence, not exact format
- Email not sent: Use perform_enqueued_jobs to execute enqueued jobs
- Authentication failures: Use post user_session_path instead of sign_in in request specs

CONFIGURATION:
- rails_helper.rb: config.include Devise::Test::IntegrationHelpers, type: :request
- rails_helper.rb: config.include ActiveJob::TestHelper (if using deliver_later)
- Test environment: config.action_mailer.delivery_method = :test
