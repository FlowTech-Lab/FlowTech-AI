Penpot - Variantes de Composants. Les variantes permettent de créer différentes versions d'un même composant. Méthode 1 nommage par slash : Navbar/Desktop, Navbar/Mobile, Navbar/Tablet. Méthode 2 création directe : sélectionner le composant principal, panneau Design → Create variant, définir les propriétés (Taille, Couleur, État, etc.). Propriétés de Variantes Recommandées : Size (Desktop, Tablet, Mobile), State (Default, Active, Hover), Theme (Light, Dark), Type (Primary, Secondary).
