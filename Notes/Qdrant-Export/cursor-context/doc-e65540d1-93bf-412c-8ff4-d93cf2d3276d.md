FlowTech-AI Samba Network Share Configuration:
- Image: ghcr.io/servercontainers/samba:latest
- Network mode: host (required for Windows discovery)
- Capability: CAP_NET_ADMIN (required for WSDD2)
- Share path: ./Notes mapped to /shares/notes
- Username: admin
- Password: SAMBA_PASSWORD (generated in .env)
- Windows access: \\YOUR_SERVER_IP\notes
- Mac/Linux access: smb://YOUR_SERVER_IP/notes
- Windows discovery: Uses WSDD2 (Web Services Discovery) for Windows 10/11
- Avahi name: DEV-FLOWTECH-LAB (configurable)
- Share configuration: SAMBA_VOLUME_CONFIG_notes in .env with multiline YAML syntax
- Use case: Edit Markdown notes with Obsidian or any text editor from Windows/Mac/Linux
