Obsidian Implementation Plan - Plan d'implémentation prioritaire

## Obsidian Implementation Plan - Perplexity Priority

### Source
Perplexity AI - Plan d'implémentation prioritaire du 20 janvier 2025
**Objectif** : Implémentation structurée des plugins et workflows Obsidian DevOps

### Stratégie Principale
**Prioriser d'abord les plugins à fort impact immédiat** (réduction orphelins, liens bidirectionnels), puis déployer progressivement l'automatisation et l'intégration stack.

### Timeline d'Implémentation (4 Semaines)

#### Semaine 1 - Plugins Critiques
**Objectif** : -10% orphelins, scan quotidien OK

##### J1 - Unlinked Mentions
- **Installation** : Plugin de détection mentions non liées
- **Configuration** : 
  - Scan quotidien automatique
  - Seuil de 5 mentions max par note
- **Validation** : UT Dataview pour liste orphelins

##### J2 - Orphan Explorer
- **Installation** : Visualisation et extraction orphelins
- **Configuration** :
  - Seuil de détection à 0 liens entrants
  - Audit initial complet
  - Export CSV orphelins
- **Validation** : Vérifier réduction de 10% orphelins

##### J3 - Auto Link Title
- **Installation** : Création liens bidirectionnels
