RSpec ActiveJob and ActionMailer Testing Best Practices:

ACTIVEJOB TESTING:
- Include ActiveJob::TestHelper in test files using deliver_later
- Use perform_enqueued_jobs block to execute enqueued jobs synchronously
- Pattern: perform_enqueued_jobs do ... expect ... end
- Check ActionMailer::Base.deliveries for sent emails

ACTIONMAILER TESTING:
- Problem: Emails sent with deliver_later are enqueued, not sent immediately
- Solution: Wrap test in perform_enqueued_jobs block
- Mailer body testing: Use decoded body for multipart emails (html_part.decoded)
- Date testing: Check for year and digits, not exact format (locale variations)
- Price testing: Check for amount presence, not exact format (10,00 vs 10.00)

EXAMPLE REQUEST SPEC WITH EMAIL:
```ruby
require 'active_job/test_helper'

RSpec.describe 'Events', type: :request do
  include ActiveJob::TestHelper

  it 'sends email when user registers' do
    user = create(:user)
    event = create(:event, :published)
    post user_session_path, params: { user: { email: user.email, password: 'password123' } }

    perform_enqueued_jobs do
      expect do
        post attend_event_path(event)
      end.to change { Attendance.count }.by(1)
    end

    expect(ActionMailer::Base.deliveries.count).to eq(1)
  end
end
```

EXAMPLE MAILER SPEC:
```ruby
RSpec.describe EventMailer, type: :mailer do
  let(:mail) { EventMailer.attendance_confirmed(attendance) }

  it 'includes event details in body' do
    html_part = mail.body.parts.find { |p| p.content_type.include?('text/html') }
    body_content = html_part ? html_part.decoded : mail.body.decoded
    expect(body_content).to include(event.location_text)
  end
end
```

CONFIGURATION:
- config/environments/test.rb: config.action_mailer.delivery_method = :test
- rails_helper.rb: config.include ActiveJob::TestHelper (if using deliver_later)
