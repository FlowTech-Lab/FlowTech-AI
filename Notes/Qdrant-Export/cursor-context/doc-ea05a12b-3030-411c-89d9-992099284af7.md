## Flow Tuning FPV - Deployment

### Application Rails 8 API-first Complète
L'application Flow Tuning FPV est maintenant entièrement configurée avec :

### Modèles créés
- **FlightDataRaw** : Stockage des données brutes des fichiers .bbl
- **FlightMetric** : Métriques extraites et structurées
- **FlightSuggestion** : Recommandations d'IA pour l'optimisation PID
- **User** : Utilisateurs de la plateforme

### Services et Jobs
- **BlackboxParser** : Service de parsing des fichiers .bbl
- **ParseFlightJob** : Job de traitement asynchrone
- **FlightAnalysisJob** : Job d'analyse IA

### Base de données
- **PostgreSQL** : Base de données principale (Docker)
- **Redis** : Cache et queue pour Sidekiq (Docker)

### Commandes de Démarrage
```bash
# Démarrage de tous les services
docker-compose up -d

# Vérification des services
docker-compose ps

# Initialisation de la base de données
bin/rails db:create db:migrate db:seed

# Démarrage du serveur Rails
bin/rails server -b 0.0.0.0 -p 3000

# Démarrage de Sidekiq (jobs asynchrones)
bundle exec sidekiq
```
