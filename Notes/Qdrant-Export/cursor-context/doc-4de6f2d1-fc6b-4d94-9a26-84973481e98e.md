52Pi Mini Tower Kit V2 - GPIO Configuration & File Permissions (October 26, 2025)

ARCHITECTURE GPIO:
- GPIO 14: Ventilateur PWM (25kHz), matériel
- GPIO 18: LEDs WS2812B 8x8 matrix (moodlight)
- GPIO 2/3: I2C OLED SSD1306

CONFLITS POTENTIELS:
- GPIO 18 utilisé par moodlight (LEDs) et peut interférer avec PWM ventilateur si mal configuré
- Solution: séparation complète (GPIO 14 pour fan, GPIO 18 pour LEDs)

FICHIERS & PERMISSIONS:
- /usr/local/minitower/: appartient à flowtech:flowtech (modifiable par VS Code)
- /usr/bin/moodlight: appartient à flowtech:flowtech
- /etc/systemd/system/minitower*.service: appartient à flowtech:flowtech
- Configuration: chown flowtech:flowtech pour permettre édition sans sudo

SERVICES SYSTEMD:
1. minitower_fan_pwm.service: contrôle ventilateur (GPIO 14), température 40-55°C
2. minitower_moodlight.service: LEDs décoratifs (GPIO 18), binaire C
3. minitower_temp_led.service: LEDs basé température (GPIO 18), Python (en développement)
4. minitower_oled.service: affichage système (I2C)

COMMANDE PERMISSIONS:
sudo chown -R flowtech:flowtech /usr/local/minitower /usr/bin/moodlight /etc/systemd/system/minitower*.service
