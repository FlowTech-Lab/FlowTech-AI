Optimization complète de l'affichage OLED MiniTower (SSD1306 128x64)

SYSTÈME
- Raspberry Pi 4 avec kit ABS MiniTower
- Affichage OLED SSD1306 128x64 (I2C)
- Service systemd : minitower_oled.service
- Fichier : /usr/local/minitower/sys_histogram.py (copie de oled_compact.py)

LAYOUT FINAL OPTIMISÉ
Structure de l'écran :
1. Ligne haut : IP + CPU% (ex: "192.168.1.100 CPU 45%")
2. Lignes milieu : 4 barres CPU (C1, C2, C3, C4) en horizontal
   - Layout 2x2 (2 barres par ligne)
   - Barres horizontales avec bordures blanches
   - Hauteur barre : 8px, largeur : 40px
   - Positions : y1=18 (C1/C2), y2=32 (C3/C4)
3. Ligne bas : RAM% + TEMP°C + FAN% (ex: "RAM 25% 45°C FAN 30%")

DONNÉES AFFICHÉES
- get_cpu_temp() : vcgencmd measure_temp
- get_fan_pwm() : lire /var/log/minitower/telemetry.log (Duty=)
- get_cpu_loads() : psutil.cpu_percent(percpu=True) pour 4 cores
- get_ip_address() : socket connect to 8.8.8.8
- RAM : psutil.virtual_memory().percent
- CPU total : psutil.cpu_percent()

ESPACEMENT & FORMATAGE
- Labels + espace + valeur (ex: "CPU 45%" au lieu de "CPU45%")
- 1 seul espace entre chaque valeur en ligne basse
- Truncation IP si > 21 caractères (fallback : "C 45%")
- Refresh interval : 2.0 secondes

FONCTIONS RENDUES
- draw_bordered_bar_horizontal() : barre horizontale avec bordure
- Border rectangle noir, fill blanc selon pourcentage
- Fill calculé : fill_width = int((fill_pct / 100) * (width - 2))

PROBLÈMES RÉSOLUS
1. Overlapping elements → Layout 2x2 horizontal
2. Barres verticales écrasaient labels → Passage horizontal
3. RAM barre inutile (déjà en %) → Supprimée
4. "..." troncature → Supprimée, espaces optimisés
5. Labels collés aux valeurs → Espaces ajoutés
6. Débordement ligne basse → Espaces réduits autour température

AUTRES SERVICES PARALLÈLES
- minitower_fan_pwm.service : Gestion PWM ventilateur (GPIO14)
- minitower_temp_led.service : LEDs température (GPIO18, WS2812B)
