FlowTech-AI Authentication and Credentials:
Services with authentication:
1. n8n (Web UI): N8N_BASIC_AUTH_USER / N8N_BASIC_AUTH_PASSWORD
2. Langfuse (Web UI): LANGFUSE_INIT_USER_EMAIL / LANGFUSE_INIT_USER_PASSWORD
3. PostgreSQL (Database): POSTGRES_USER / POSTGRES_PASSWORD / POSTGRES_DB
4. Samba (File Share): Username: admin, Password: SAMBA_PASSWORD
5. OpenWebUI: First user registration becomes admin (no pre-configured credentials)

Services without authentication (internal network only):
- Ollama, Qdrant, Redis, SearxNG, MCP-Qdrant, MCP-Knowledge

All credentials are auto-generated during init.sh and stored in .env file
