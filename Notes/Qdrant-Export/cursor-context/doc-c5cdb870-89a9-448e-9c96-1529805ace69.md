Penpot – Layouts CSS générés (Flex)
- Mapping: flex-direction, flex-wrap, align-items, justify-content, column-gap, row-gap, padding, width/height auto ou fixe
- Exemple navbar: display:flex; direction:row; justify-content:space-between; align-items:center; gap:16px; padding:12px 24px; height:64px
- Utilisation directe en production CSS.
