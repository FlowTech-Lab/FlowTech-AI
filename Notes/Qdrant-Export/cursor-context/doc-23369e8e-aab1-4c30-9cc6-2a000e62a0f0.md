IA Locale Assistant - Architecture et déploiement

## IA Locale Assistant - Architecture

### Architecture & Déploiement
- **Hébergement hybride** : Développement sur PC Fixe, stockage et exécution sur serveur Proxmox
- **Backend** : Python (FastAPI, Flask) ou Node.js
- **LLM** : Ollama (Mistral, Mixtral, Phi-3)
- **Base mémoire** : ChromaDB ou PostgreSQL pour la mémoire longue durée
- **Stockage** : Btrfs / NAS / Nextcloud
