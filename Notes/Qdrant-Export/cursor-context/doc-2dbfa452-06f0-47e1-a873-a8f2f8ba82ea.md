FINAL SIMPLIFICATION: Cursor 2025 config is now SINGLE USER RULES file only. No more separate Project Rules - everything in one YAML file in Settings → Rules & Memories → User Rules. This includes: agent_language, MCP servers, Qdrant params, infra_tags, Shape Up settings, anti_patterns detection, chunking params, vault paths, stack services, all in unified YAML. Advantages: one place to maintain, no conflicts, cloud sync, simpler setup (saves 20 min). Updated guide: Notes/30-Resources/Cursor-Optimisation-Complete-Installation.md.
