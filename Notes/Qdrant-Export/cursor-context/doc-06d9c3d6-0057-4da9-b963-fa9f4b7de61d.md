FlowTech-AI Project Architecture Overview:
- Production-ready self-hosted AI stack for developers
- One-command deployment with init.sh script
- Docker Compose orchestration with 11 core services
- MCP (Model Context Protocol) integration for Cursor IDE
- RAG (Retrieval Augmented Generation) with OpenWebUI
- Vector database with Qdrant (1024-dim embeddings using BAAI/bge-large-en-v1.5)
- Workflow automation with n8n
- LLM observability with Langfuse
- Network file sharing with Samba (SMB protocol)
- PostgreSQL for metadata storage, Redis for caching
- SearxNG for web search integration
