Penpot - Création d'une Navbar Fonctionnelle, Étape 1 Structure de Base. Créer l'élément de navigation de base : dessiner un conteneur rectangulaire, ajouter une icône SVG depuis css.gg ou autre bibliothèque, ajouter le texte du label, appliquer un layout Flex vertical centré. Configuration du layout : sélectionner le groupe d'éléments, appliquer Flex Layout (Ctrl/⌘ + Shift + A), direction Column pour icône + texte, alignement Center/Center, gap 4px entre icône et texte. Transformation en composant : sélectionner l'élément complet, clic droit → Create component (ou Ctrl/⌘ + K), renommer le composant NavItem.
