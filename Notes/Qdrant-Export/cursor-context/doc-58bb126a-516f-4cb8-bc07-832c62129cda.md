RSpec Request Specs Authentication Pattern for Rails 8:

PROBLEM: sign_in helper fails in request specs with RuntimeError "Could not find a valid mapping"

SOLUTION: Use post user_session_path for authentication in request specs

WORKING PATTERN:
```ruby
it 'allows user to create event' do
  user = create(:user)
  post user_session_path, params: {
    user: {
      email: user.email,
      password: 'password123'
    }
  }
  # ... test code ...
end
```

REUSABLE HELPER:
Create spec/support/request_authentication_helper.rb:
```ruby
module RequestAuthenticationHelper
  def login_user(user)
    post user_session_path, params: {
      user: {
        email: user.email,
        password: user.password || 'password123'
      }
    }
  end
end

RSpec.configure do |config|
  config.include RequestAuthenticationHelper, type: :request
end
```

DIFFERENCES BY TEST TYPE:
- Request specs: post user_session_path (recommended)
- System specs: login_as(user) custom helper
- Controller specs: sign_in user (works)

CONFIGURATION:
- rails_helper.rb must include: config.include Devise::Test::IntegrationHelpers, type: :request
- Factory user must have password: 'password123' or use user.password in helper
