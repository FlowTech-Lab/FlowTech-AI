Penpot - Templates, Ressources et Code Handoff. Templates Disponibles : Basic Layouts Template (layouts Flex/Grid prêts à utiliser), Wireframing Kit (composants de base pour prototypage), Icon Libraries (collections d'icônes css.gg et autres). Import de Ressources Externes : Depuis Penpot Hub (https://penpot.app/libraries-templates), Import manuel (télécharger .penpot → Import dans dashboard), Migration Figma (plugin communautaire disponible). Avantages Techniques : Code CSS natif (export direct des propriétés Flex/Grid), Standards web (HTML/CSS compatible sans conversion), Inspection (panneau Inspect avec snippets de code), Annotations (documentation intégrée aux composants). Formats supportés : Code CSS/HTML natif, Propriétés de layout exactes, Design tokens au format W3C DTCG, SVG pour les icônes et illustrations.
