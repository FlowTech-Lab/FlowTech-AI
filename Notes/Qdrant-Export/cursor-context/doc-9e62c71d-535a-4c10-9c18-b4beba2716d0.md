FactoryBot Best Practices for Rails 8 Events Testing:

TRAITS FOR DATE-BASED EVENTS:
- Always define :upcoming and :past traits in factories
- Pattern: trait :upcoming do start_at { 1.week.from_now } end
- Pattern: trait :past do start_at { 2.days.ago } end
- Default: start_at { 3.days.from_now } in base factory

USAGE:
- Good: create(:event, :published, :upcoming, title: 'Sortie Roller')
- Bad: create(:event, :published, start_at: 1.week.from_now, title: 'Sortie Roller')

TRAITS FOR PARTICIPANT LIMITS:
- trait :with_limit do max_participants { 20 } end
- trait :unlimited do max_participants { 0 } end
- Default: max_participants { 0 } in base factory (unlimited)

COMPLETE FACTORY PATTERN:
```ruby
FactoryBot.define do
  factory :event do
    start_at { 3.days.from_now }
    max_participants { 0 }
    
    trait :published do
      status { 'published' }
    end
    
    trait :upcoming do
      start_at { 1.week.from_now }
    end
    
    trait :past do
      start_at { 2.days.ago }
    end
    
    trait :with_limit do
      max_participants { 20 }
    end
  end
end
```

COMMON MISTAKES:
- Missing :upcoming trait causes tests to fail
- Manually specifying dates instead of using traits
- Not defining default values in base factory
