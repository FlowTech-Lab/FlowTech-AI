Structure Ops avec Watchdog - Docker Compose Principal et Commandes Déploiement

Docker Compose Principal (/ops/docker-compose.yml racine):
- Services avec extends depuis dev/, staging/, production/
- Profiles: dev, staging, production
- Permet de gérer tous les environnements depuis la racine

Commandes de Déploiement:
- Staging: cd ops/staging && docker-compose -f docker-compose.yml -f watchdog/docker-compose.watchdog.yml up -d
- Production: cd ops/production && docker-compose -f docker-compose.yml -f watchdog/docker-compose.watchdog.yml up -d
- Vérifier logs: docker logs -f watchtower-staging
- Forcer rollback: docker exec watchtower-production /app/scripts/rollback.sh
- Consulter logs rollback: tail -f ops/logs/production/rollback-*.log
