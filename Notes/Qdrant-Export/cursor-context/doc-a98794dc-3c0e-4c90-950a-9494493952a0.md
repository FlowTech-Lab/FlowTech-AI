MiniTower OLED Display System - Documentation Complète Finalisée

HARDWARE:
- Écran: SSD1306 128×64 pixels
- Interface: I2C (GPIO 2 SDA, GPIO 3 SCL)
- Adresse I2C: 0x3C
- Service: minitower_oled.service (systemd)

LAYOUT OPTIMISÉ:
1. Ligne 1 (haut): IP + CPU% (ex: "192.168.1.100 CPU 45%")
2. Lignes 2-3: 4 barres CPU cores en 2×2 (C1 C2, C3 C4)
   - Barres horizontales 8px hauteur, 40px largeur
   - Bordures blanches, remplissage selon charge
   - Positions: y1=18 (C1/C2), y2=32 (C3/C4)
3. Ligne 4 (bas): RAM% + TEMP°C + FAN% (ex: "RAM 25% 45°C FAN 30%")

DONNÉES AFFICHÉES:
- get_cpu_temp(): vcgencmd measure_temp
- get_cpu_loads(): psutil.cpu_percent(percpu=True) pour 4 cores
- get_ip_address(): socket connect to 8.8.8.8
- get_fan_pwm(): Parse /var/log/minitower/telemetry.log
- get_ram_usage(): psutil.virtual_memory().percent
- get_cpu_usage(): psutil.cpu_percent()

FORMATAGE:
- Labels + espace + valeur (ex: "CPU 45%")
- 1 espace entre valeurs ligne basse
- Truncation IP si > 21 chars (fallback: "C 45%")
- Pas de troncature "..."
- Refresh: 2.0 secondes

FONCTION RENDU:
- draw_bordered_bar_horizontal(): barre horizontale avec bordure
- Border noir, fill blanc selon %
- fill_width = int((fill_pct / 100) * (width - 2))

INSTALLATION:
- Script: /usr/local/minitower/sys_histogram.py
- Alternative: /usr/local/minitower/oled_compact.py
- Bibliothèque: luma.oled
- Service: /etc/systemd/system/minitower_oled.service

SCRIPTS DISPONIBLES:
1. sysinfo.py: Informations système basiques
2. temperature.py: Affichage température uniquement
3. sys_histogram.py: Histogramme système complet (actuel)

PROBLÈMES RÉSOLUS:
1. Overlapping elements → Layout 2×2 horizontal
2. Barres verticales écrasaient labels → Passage horizontal
3. RAM barre inutile → Supprimée
4. Troncature "..." → Supprimée, espaces optimisés
5. Labels collés valeurs → Espaces ajoutés
6. Débordement ligne basse → Espaces réduits

INTÉGRATION:
- Fonctionne en parallèle avec fan PWM (GPIO14) et LED temp (GPIO18)
- Données synchronisées: temp OLED = temp LED, fan PWM OLED = fan duty
- 3 indicateurs complémentaires: LED + OLED + Ventilateur
