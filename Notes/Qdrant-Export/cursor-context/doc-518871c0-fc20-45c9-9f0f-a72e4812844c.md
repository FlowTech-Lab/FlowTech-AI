52Pi Mini Tower Kit V2 - Architecture complète: 3 services systemd séparés. 1) Ventilateur PWM: /usr/local/minitower/fan_pwm.py (Python, GPIO 14, 25kHz, contrôle température). 2) LEDs moodlight: /usr/bin/moodlight (binaire C compilé, GPIO 18, WS2812B, éclairage décoratif). 3) OLED: /usr/local/minitower/sys_histogram.py (Python, I2C GPIO2/3, monitoring système). Services: minitower_fan_pwm.service, minitower_moodlight.service, minitower_oled.service. Architecture justifiée: séparation sécurité, performance PWM vs LEDs, maintenance indépendante.
