CRITICAL UPDATE: Cursor IDE 2025 configuration changed completely. No more System Prompt or .cursorrules file. New approach: 1) User Rules (Settings → Rules & Memories → User Rules) in YAML format for global config including agent_language: fr, Shape Up rules, anti-patterns detection, MCP prioritization, score thresholds. 2) Project Rules (same menu) in INI format for project-specific config like vault paths, chunking params, stack services. 3) Background Agents configured in Settings → Background Agents interface (not file-based). Agent can respond in French without performance loss. Community validated by forum.cursor.com and labac-dev GitHub. Updated guide: Notes/30-Resources/Cursor-Optimisation-Complete-Installation.md
