FlowTech-AI Stack - Infrastructure IA Multi-Agent

## FlowTech-AI Stack

### Personal Multi-Agent AI Stack
Infrastructure IA complète déployée localement, conçue pour les besoins FPV, infrastructure, automation et documentation de FlowTech.

### Quick Start
```bash
chmod +x init.sh
./init.sh
```

Le script `init.sh` optimisé gère automatiquement :
- Démarrage séquentiel des services avec dépendances
- Mode DEV avec reset complet optionnel
- Gestion d'erreurs et logging complet
- Permissions automatiques (chmod)
- Configuration des variables d'environnement
- Vérification de l'espace disque

### Architecture Multi-Agent
#### Agent Principal (Orchestrateur)
- **Rôle** : Coordination des tâches et routage intelligent
- **Technologies** : Python, FastAPI, Redis
- **Fonctions** : Analyse des requêtes, délégation aux agents spécialisés

#### Agents Spécialisés
- **Infrastructure Agent** : Monitoring, configuration réseau, Proxmox
- **FPV Agent** : Analyse Betaflight, tuning PID, optimisation drones
- **Trading Agent** : Analyse financière, stratégies de trading
- **Documentation Agent** : Génération et maintenance documentation

### Stack Technique
- **LLM** : Ollama (Mistral, Mixtral, Phi-3)
- **Embeddings** : ChromaDB pour mémoire vectorielle
- **Vector Store** : Recherche sémantique et RAG
- **Container** : Docker + Docker Compose
- **Queue** : Redis pour communication inter-agents
- **Database** : PostgreSQL pour données persistantes
- **Storage** : Btrfs avec compression pour fichiers volumineux
