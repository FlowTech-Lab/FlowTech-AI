## FlowTech Design System

### Vue d'ensemble
Charte graphique basée sur la page d'erreur 503 de FlowTech-LAB, offrant un design moderne, professionnel et cohérent avec l'identité visuelle de l'entreprise.

### Palette de Couleurs
#### Couleurs Principales
```css
--bg: #0b1020           /* Fond très sombre */
--card: #121a31         /* Panneau/carte */
--txt: #f0f6ff          /* Texte principal */
--txt-rgb: 240,246,255  /* RGB du texte pour rgba() */
--muted: rgba(154,167,199,0.85)        /* Texte secondaire */
--accent: #8ebcfc       /* Bleu accent principal */
--accent-hover: #5a98ef /* Bleu accent au survol */
```

