FlowTech-AI Deployment and Installation:
- Quick start: git clone, cd FlowTech-AI, sudo ./init.sh
- Total deployment time: ~5 minutes
- init.sh script handles: environment setup, Docker Compose orchestration, credentials generation, Qdrant collection creation
- Two modes: Normal mode (preserves data) and DEV mode (complete reset with --dev flag)
- Non-interactive mode: --non-interactive flag for CI/CD pipelines
- Data preservation: Normal mode uses docker compose down without --volumes flag
- Log files stored in logs/ directory with timestamp
- Health checks for all critical services (PostgreSQL, Redis, MinIO, ClickHouse)
- Automatic Qdrant collection creation with named vectors (fast-bge-large-en-v1.5)
