Anubis
Web scrapers continue to be anoying, although with the datacenter move we
have increased capacity so we can weather it much better. Still, thats
unlikely to last forever, so I've taken this time to look at putting
anubis in place to help protect things.
stg.pagure.io has anubis enabled now if you want to take a look at it.
In the case of pagure.io, things were a bit challenging as they are still
RHEL8 instances, but I was pretty easily able to just use a anubis
container there. It's already blocked a lot of scraper traffic.
Things should be pretty much in place to enable for pagure.io, which
we might consider doing after the beta freeze (or perhaps sooner if
we get hit by another big wave).
