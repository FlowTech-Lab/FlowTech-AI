Fun with vHMC
So, our new power10 machines can run as a single kvm instance, which we
thought would be great, but sadly, doesn't allow for guests running on that
hypervisor to do nested virt. So, we reluctantly got a vHMC (virtual
Hardware Management Console). This is a vm that you run that lets you
manage the machines at a lower level, allowing lpars for seperate
instances that each can do virt.
It's still not 100% working as we want, but we made a lot of progress on it.
I'll probibly provide a much longer recap of it once we get it working.
It is very much not clear how to set it up and the way it works is very confusing.
Just one example: It talks to the hardware on it's mgmt ip. great. But then
it tells the hardware to setup a second ip on the internal powervm in the
firmware that needs a second ip address on the same physical mgmt adapter
to talk to it via a seperate connection. There's many more things like that.
