Vérifiez toujours robots.txt avant de crawler, si le site en dispose. Cela
permet de respecter les règles d’accès définies par le propriétaire du site.
from urllib.robotparser import RobotFileParser
def can_crawl(url):    rp = RobotFileParser()    rp.set_url(url + '/robots.txt')    rp.read()    return rp.can_fetch('*', url)


Utilisez un User-Agent identifiable et respectez les délais :
import trafilatura.downloadsimport time
trafilatura.downloads.DEFAULT_HEADERS['User-Agent'] = 'MonBot/1.0 (contact@example.com)'
def crawl_respectfully(urls, delay=2):    for url in urls:        if can_crawl(url):            downloaded = fetch_url(url)            result = extract(downloaded)            time.sleep(delay)            yield result
