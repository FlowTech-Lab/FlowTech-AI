Maintain Hunter’s Mark.
Maintain Serpent Sting.
Use Stampede on Cooldown.
Use Rapid Fire on Cooldown.
Use A Murder of Crows on Cooldown.
Use Rabid (Ferocity Pet Spell) on Cooldown.
Use Glaive Toss on Cooldown.
Use Explosive Shot on Cooldown. Don’t forget Lock and Load procs.
Use Black Arrow on Cooldown.
Use Kill shot whenever you can.
Spend focus on Arcane shot if you have 70+ Focus.
Cast Cobra shot.

Survival Hunter Opener
Regarding the opener, it’s pretty easy. Cast Hunter’s Mark, place one Explosive Trap and a Snake Trap, Pre-cast Cobra Shot, then use Glaive Toss, Rabid and Stampede, apply Serpent Sting, use Explosive Shot and Black Arrow on cooldown, use Fervor, Murder of Crows, and continue with the normal rotation.
AoE Rotation & Priority

Maintain Serpent Sting.
Use Barrage on Cooldown.
Use Explosive Trap on Cooldown.
If there are more than 4 enemies, spam Multi-shot. If not, just continue with the single target rotation, replacing Arcane Shot with Multi-Shot.
