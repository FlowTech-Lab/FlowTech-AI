En outre, traiter le code des pipelines avec la même rigueur que le code de
l’application elle-même est essentiel pour assurer la sécurité et
l’optimisation. Dans un environnement où les déploiements fréquents et les

être à la fois robustes et flexibles.
Notions importantes
Avant de voir comment créer des templates Gitlab CI/CD, il est important
d’introduire quelques notions.
Extends
extends permet à un job d’hériter des configurations d’un autre, tout en lui
permettant d’ajouter ou de surcharger certaines parties de cette configuration.
Cela aide à éviter les répétitions et à garder les pipelines DRY (Don’t Repeat
Yourself).
Imaginons que vous ayez une configuration de base pour tous les jobs de test :
.test_base.yml.test_base:  stage: test  script:    - echo "Exécution des pré-tests..."
