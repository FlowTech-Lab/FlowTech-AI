Exercices pratiques : Définir et utiliser des facts personnalisés dans Ansible
Vous avez maintenant compris l’utilité des custom facts Ansible pour adapter
dynamiquement vos playbooks aux caractéristiques spécifiques de chaque hôte.
Passons à la pratique pour apprendre à créer, déployer et exploiter ces faits
personnalisés.
Dans ce TP, vous allez créer des fichiers .fact au format INI et JSON, les
copier dans le répertoire attendu par Ansible, puis utiliser les données qu’ils
contiennent dans vos playbooks à l’aide de conditions.
👉 Travaux pratiques : TP 10 : Utilisation des Custom Facts
Ansible ↗
Ces exercices couvrent notamment :

La création de fichiers de faits personnalisés dans
/etc/ansible/facts.d/
L’utilisation des formats INI et JSON
L’accès aux faits via ansible_local.* dans un playbook
L’ajout de conditions when basées sur ces faits
La simulation d’un provisionnement cloud avec des fichiers .fact
préinstallés
