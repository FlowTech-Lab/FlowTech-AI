run/ : Un exemple de rôle Ansible, avec tous les composants habituels
d’un rôle (tasks, handlers, vars etc.).

tests/ : Contient l’inventaire utilisé pour les tests du rôle.




test-requirements.txt : Fichier listant les dépendances spécifiques
nécessaires pour exécuter les tests du projet.
tests/

integration/ : Tests d’intégration, validant que les différents
composants fonctionnent ensemble.

hello_world/ : Un scénario de test d’intégration spécifique.


unit/ : Tests unitaires pour valider les plus petites unités de code,
comme les modules et plugins.


tox-ansible.ini : Fichier de configuration pour Tox, un outil de gestion
d’environnements de test, souvent utilisé pour automatiser les tests Ansible.
