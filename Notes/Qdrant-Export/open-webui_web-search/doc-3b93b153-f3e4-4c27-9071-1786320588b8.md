On top of that you make a logical partition that runs a VIOS server.
(Virtual I/O). This instance (can) provide network, storage, etc to
other partitions. Then you have those other partitions that run
fedora or RHEL or Centos. They can either use a vnic provided via
the VIOS (so it's just one interface they use thats backed by
two physical ones in a bond in the VIOS), or they can directly use
a nic via SR-IOV. In which case they get 2 interfaces and we can run
normal linux bonding on top of it. With a vnic you CANNOT run a
linux bridge on your partition, but with SR-IOV you can do a bridge.
So, we want both for different use cases. A physical nic can only do
one mode or the other.
