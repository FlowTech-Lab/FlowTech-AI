L’Expertise (Expertise) : Atteindre le cap de 7.5% (2550 score d’Expertise (Expertise))
Une modification notable introduite avec Mists of Pandaria est l’exigence de score d’Expertise (Expertise Rating) pour les Chasseurs, car leurs tirs à distance peuvent désormais être esquivés (dodged) par les ennemis.1 Le cap d’Expertise (Expertise) est également de 7.5%, correspondant à 2550 points de score d’Expertise (Expertise Rating).4 L’atteinte de ce cap est aussi cruciale que celle du cap de Toucher (Hit) pour s’assurer que les attaques ne sont pas esquivées, garantissant ainsi une performance constante et prévisible.
