Next (small) datacenter move planning underway
We have a small number of machines in a datacenter often referred to as
rdu2 community cage. With our big datacenter move eariler this year to
rdu3, we are going to be moving the rdu2 community cage gear over to
rdu3 to consolidate it.
There's only a few machines there, but there's 2 services people will
notice: pagure.io and download-cc-rdu01. We are currently trying to see
if we can arrange things so we can just migrate pagure.io to a new machine
in rdu3 and switch to it. If we can do that, downtime should be on the
order of a few hours or less. If we cannot for some reason, the outage
will be on the order of a day or so while the machine it's on is moved.
For download-cc-rdu01, we will just likely have to have it down for a day
or so, which shouldn't be too bad since there's many other mirrors
to pull from.
It's looking tenatively like this might occur in november.
So, look for more information as we know it. :)
