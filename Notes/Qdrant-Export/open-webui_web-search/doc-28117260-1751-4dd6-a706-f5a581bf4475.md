Fichiers de configuration

.gitignore : Liste des fichiers et répertoires à exclure du contrôle de
version Git.
.isort.cfg : Configuration pour l’outil isort, utilisé pour trier et
organiser les imports dans les fichiers Python.
.pre-commit-config.yaml : Configuration pour l’outil pre-commit, qui
exécute des vérifications automatiques avant chaque commit, comme le
formatage de code ou l’exécution de tests.
.prettierignore : Définit les fichiers à ignorer pour l’outil
Prettier, utilisé pour formater le code.
