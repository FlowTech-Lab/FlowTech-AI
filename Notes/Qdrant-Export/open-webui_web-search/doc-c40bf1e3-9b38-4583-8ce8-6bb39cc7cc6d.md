8. Season 3 Tier Set for Marksmanship Hunter
The Tier Set is comprised of 5 items, all carrying the Midnight Herald's moniker.
In Season 3, there are two Set Bonuses per spec, one for each Hero Talent.
8.1.  Dark Ranger Hero Talent Tier Set Bonus for Marksmanship Hunter

 Hunter Dark Ranger 11.2 Class Set 2pc —  Black Arrow damage
increased by 10%,  Bleak Powder damage increased by 20%, and the
cooldown of  Trueshot is reduced by 30 sec.
 Hunter Dark Ranger 11.2 Class Set 4pc —  Withering Fire's
damage increased by 50%, and whenever you consume  Deathblow, you have
a 50% chance to cause all  Withering Fire  Black Arrow barrages
in your next  Trueshot to fire 1 additional  Black Arrow.
