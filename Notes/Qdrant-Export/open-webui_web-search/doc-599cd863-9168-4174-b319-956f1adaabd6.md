Mailing list issue with gmail accounts
Just a early heads up that we had a bit of an issue last night with
the fedora devel list. As near as I can tell, my current theory is:

Some spam got through to the list. I'm still not 100% sure how it
got though, but it was using <> and playing other weird tricks.
That spam had some bad archives attached to it.
gmail subscribers got those emails and then google decided to block
lists.fedoraproject.org because of it.
lists.fedoraproject.org got the bounces from google and disabled
a bunch (~340) users.

I deleted the spam from archives and put in place some things on the list
to hopefully ensure it doesn't allow such posts thru.
Next week we will see if we can't re-enable all those users,
provided google is accepting lists emails again.
