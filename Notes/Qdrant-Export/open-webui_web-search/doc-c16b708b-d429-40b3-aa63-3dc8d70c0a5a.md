Installation et configuration
Trafilatura peut être utilisé aussi bien en ligne de commande qu’en tant
que module Python. Son installation est simple et rapide, que ce soit sur un
environnement local ou dans un conteneur.
Installation via pip
Il est recommandé d’utiliser un environnement virtuel pour éviter les
conflits de dépendances :
Terminal windowpython -m venv venvsource venv/bin/activatepip install trafilatura lxml_html_clean
Modules complémentaires
Pour améliorer les performances, certains modules optionnels peuvent être
ajoutés :
Terminal windowpip install trafilatura[all] lxml_html_clean
