vHMC for power10
Thanks to a ton of work/investigation by Fabian, we think we have figured out
a setup for the power10 machines that will work. We do need to get some more
nvme drives for them because they have 4 6TB drives currently and VIOS will take
2 of them (and only use a tiny fraction of those) leaving only 2 drives,
and if we want them to be HA, would mirror volumes, so that would leave...
1 drive worth of space. So, we are going to get some more smaller ones for
VIOS and then we will be able to use the space much better.
We also need to adjust the network due to wanting to use some physical cards
with SR-IOV (virtualized network on the card) and some as vnic's and still
have them HA over 2 physical cards. The setup is nicely complex, but
I think we can get it all working now.
So, you have the power10 box, it runs a powervm layer in the firmware.
On top of that you make a logical partition that runs a VIOS server.
