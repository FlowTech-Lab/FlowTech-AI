Tirer un modèle de démarrageDans l'application, parcourez et téléchargez un modèle. Ou dans un terminal :  « ollama run llama3:8b ».«Cela téléchargera le modèle et vous amènera à une invite : tapez une question et lancez-vous. Vous pouvez parcourir de nombreux modèles (Gemma, Llama, Qwen, OLMo, etc.) dans la bibliothèque Ollama.










(Facultatif) Activer l'accélération GPUMaintenez vos pilotes graphiques à jour. Ollama fournit des versions Windows avec accélération AMD, et AMD documente les chemins DirectML/ROCm pour les LLM sur Radeon. Dans l'application Ollama, vérifiez que le GPU est détecté (ou surveillez l'utilisation du GPU dans le Gestionnaire des tâches pendant la génération).
