Les modules
Les modules sont un type particulier de plugin qui exécute des tâches
spécifiques. Les modules personnalisés doivent être placés sous
plugins/modules/ dans la collection.
Les modules peuvent être écrits en Python ou dans d’autres langages et Ansible
les exécutera pour effectuer des tâches comme la gestion de configurations,
l’interaction avec des API ou l’exécution de commandes sur des hôtes. Plus
d’explications sur le développment des modules
