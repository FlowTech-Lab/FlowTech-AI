Emplacement des modèles

Les modèles sont stockés dans /usr/share/ollama/.ollama/models.

Il est possible de changer l'emplacement par défaut en ajoutant une nouvelle variable d'environnement.

On éditera le service précédemment créé :
Code BASH :vim /etc/systemd/system/ollama.service

On ajoutera une variable d'environnement OLLAMA_MODELS :

Code :
[Unit]Description=Ollama ServiceAfter=network-online.target[Service]ExecStart=/usr/bin/ollama serveUser=ollamaGroup=ollamaRestart=alwaysRestartSec=3Environment="PATH=$PATH"Environment="OLLAMA_MODELS=/home/ollama/models"[Install]WantedBy=default.target


On recharge systemd :
Code BASH :systemctl daemon-reload

Et on redémarre le service :
Code BASH :systemctl restart ollama.service

Si on avait déjà des modèles installés, on pourra les déplacer :
Code BASH :mv /usr/share/ollama/.ollama/models /home/ollama/models

On pensera bien à réaffecter les droits à l'utilisateur et au groupe ollama :
Code BASH :chown -R ollama:ollama /home/ollama
