plugins/modules/ : Ce répertoire contient les modules personnalisés. Les
modules sont des scripts ou programmes exécutés par Ansible pour accomplir des
tâches spécifiques.


plugins/module_utils/ : Ce répertoire est dédié aux utilitaires de
modules. Ce sont des bibliothèques de code réutilisable que d’autres modules
peuvent importer pour faciliter des tâches complexes, comme la gestion des API
ou des formats de données spécifiques.


plugins/filters/ : Ce répertoire contient les filtres
jinja. Les filtres sont
utilisés dans les templates pour transformer les données, par exemple pour
formater une chaîne de caractères ou manipuler une liste.


plugins/callbacks/ : Ce répertoire héberge les plugins de callback, qui
permettent de modifier la sortie des exécutions de playbooks ou de capturer et
d’enregistrer des informations sur l’exécution de ces derniers.
