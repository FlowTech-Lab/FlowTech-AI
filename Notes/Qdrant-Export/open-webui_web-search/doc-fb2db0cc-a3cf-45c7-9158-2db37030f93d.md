Une fois installé, Trafilatura peut être utilisé directement depuis le
terminal :
Terminal windowtrafilatura --versionTrafilatura 2.0.0 - Python 3.10.12
Exemple simple pour extraire le texte d’une page web :
Terminal windowtrafilatura -u "https://exemple.com/article"
Le texte est affiché dans la console ou peut être redirigé dans un fichier :
Terminal windowtrafilatura -u "https://exemple.com/article" > article.txt
