plugins/inventory/ : Les plugins d’inventaire se trouvent ici. Ils
permettent de définir dynamiquement l’inventaire d’hôtes à partir de sources
externes comme des bases de données, des services cloud ou des fichiers.


plugins/actions/ : Ce répertoire contient les plugins d’actions. Ces
plugins permettent d’exécuter des actions personnalisées avant ou après les
tâches Ansible, comme la modification du comportement par défaut d’Ansible
lorsqu’il exécute une tâche.
