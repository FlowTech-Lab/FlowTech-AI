Fichiers standards de projet open source
CHANGELOG.rst : Journal des modifications de la collection, détaillant les
évolutions à chaque version.
CODE_OF_CONDUCT.md : Charte de conduite à suivre pour les contributeurs.
CONTRIBUTING : Instructions pour contribuer au projet.
LICENSE : Le fichier de licence, spécifiant les droits d’utilisation.
MAINTAINERS : Liste des mainteneurs responsables de la collection.
README.md : Présentation générale de la collection et instructions
d’utilisation.
changelogs/

config.yaml : Configuration des changelogs, probablement pour un outil
automatisé de génération de journaux de modifications.


devfile.yaml

Utilisé pour définir l’environnement de développement pour les IDE
compatibles avec les devfiles, comme Eclipse Che.


docs/

.keep : Un fichier vide qui permet de garder un répertoire vide dans
Git.
docsite/links.yml : Contient des liens utilisés dans la documentation
générée du projet, facilitant la navigation entre les sections.


extensions/
