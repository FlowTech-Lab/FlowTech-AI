Rune Dungeons can be accessed and queued for through the dungeon finder tool.Protocol Inferno is the first stage of the Elemental Rune Dungeon system, and the gear within is intended to be a catch-up system for the Firelands raid. Future stages are likely to come with the next raid tier. As of the Rage of the Firelands patch, this system is not being introduced for the Phase 2 Heroics, Zul’Aman and Zul’Gurub. It is instead exclusive to the initial lineup of Heroic dungeons, such as Cavernes de Rochenoire and Les Mortemines. Activating the Mysterious Elemental DeviceInside of each Heroic Dungeon, close to the entrance is a Mysterious Elemental Device, an object which players can interact with. To turn on Protocol Inferno Dungeon difficulty, players need to interact with the device and channel into the crystal that appears.
