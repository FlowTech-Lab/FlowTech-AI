Binding Shot will drop a tether at a target location, leashing nearby enemies.
If they travel too far they will break the leash, stunning them for 5 seconds. This is an incredibly
strong AoE stun and a powerful choice in any situation.
 Wyvern Sting is a single target sleep. This is a nice button to have, but
is not really necessary given that we already have  Freezing Trap.
 Intimidation is a single target, 3-second stun. Again, this is simply not as powerful
of an option compare to Binding Shot.

1.4. Level 45 Talents
Recommended option:  Aspect of the Iron Hawk.
This tier offers a few different ways to increase personal survivability.
