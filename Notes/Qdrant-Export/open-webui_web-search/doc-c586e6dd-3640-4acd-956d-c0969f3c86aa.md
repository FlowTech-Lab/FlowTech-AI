Installation d’Ollama
L’installation d’Ollama varie selon votre système d’exploitation. Suivez la
section correspondante.
Installation sur Linux
Pour Linux, l’installation se fait via un script automatique :
Terminal window# Télécharger et installer Ollamacurl -fsSL https://ollama.com/install.sh | sh
Vérification de l’installation :
Terminal window# Vérifier que Ollama est installéollama --version
Si la commande retourne un numéro de version, l’installation est réussie ! Sinon
vérifiez le service.
Terminal window# Vérifier le service Ollamasudo systemctl status ollamasudo journalctl -u ollama -f
Installation sur Windows

Téléchargez le fichier d’installation depuis
ollama.com/download ↗
Exécutez le fichier .exe téléchargé
Suivez l’assistant d’installation
Redémarrez votre ordinateur si nécessaire
