# Windows example
export OLLAMA_MODELS="C:\CustomModels"
Custom model paths enable centralized model management across multiple installations. This approach simplifies backup strategies and reduces storage duplication.OLLAMA_KEEP_ALIVE controls model unloading behavior:# Keep models loaded for 10 minutes
export OLLAMA_KEEP_ALIVE=10m

# Keep models loaded indefinitely
export OLLAMA_KEEP_ALIVE=-1

# Unload immediately after use
export OLLAMA_KEEP_ALIVE=0
Model persistence settings balance memory usage with response speed. Longer keep-alive times improve performance for frequent requests but consume more memory.Platform-Specific ConfigurationLinux and macOS SetupCreate a persistent environment configuration:# Add to ~/.bashrc or ~/.zshrc
echo 'export OLLAMA_NUM_PARALLEL=4' >> ~/.bashrc
echo 'export OLLAMA_HOST=0.0.0.0' >> ~/.bashrc
echo 'export OLLAMA_MODELS="/opt/ollama-models"' >> ~/.bashrc

# Reload configuration
source ~/.bashrc
