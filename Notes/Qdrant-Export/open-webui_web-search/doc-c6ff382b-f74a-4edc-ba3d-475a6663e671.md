# Bind to specific IP with custom port
export OLLAMA_HOST=192.168.1.100:11435
The default localhost binding restricts access to the local machine. Use 0.0.0.0 for network access, but implement proper security measures in production environments.OLLAMA_ORIGINS configures CORS allowed origins:# Allow specific domains
export OLLAMA_ORIGINS="https://myapp.com,https://staging.myapp.com"

# Allow all origins (development only)
export OLLAMA_ORIGINS="*"
CORS configuration prevents unauthorized cross-origin requests. Never use wildcard origins in production—specify exact domains instead.Model Storage and Path ManagementOLLAMA_MODELS sets the custom model storage directory:# Use custom model directory
export OLLAMA_MODELS="/custom/path/to/models"
