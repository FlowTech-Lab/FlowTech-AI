# Fiche Mémo — SQLite et Rails 8

### 🚀 Setup rapide
- Installer Ruby, Bundler, SQLite3, Node/Yarn si besoin.
- `rails new app --database=sqlite3` pour initialiser le projet.
- Configurer `config/environments/production.rb` pour le cache base de données.
- Générer les tables nécessaires au cache et aux jobs.
- Activer Action Cable via `config/cable.yml` avec l'adaptateur DB.

### 📦 Commandes clés
```bash
rails db:create db:migrate
rails generate active_record:cache_migration && rails db:migrate
rails solid_queue:install && rails db:migrate
rails server
```
