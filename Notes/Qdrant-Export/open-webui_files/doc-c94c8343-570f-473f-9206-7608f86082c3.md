### 📦 Commandes clés
```bash
rails c                         # Ouvre la console connectée à la BDD
rails c --sandbox               # Ouvre en bac à sable (rollback auto à la sortie)
bundle add table_print          # Ajoute un outil d'affichage tabulaire
alias rc="rails c"              # Alias pratique (shell)
```
```rb
# Exemples rapides ActiveRecord (Model générique: User)
User.all                        # Lire tout
User.create(first_name: "INPUT")# Créer et sauver
u = User.new(...); u.save       # Créer puis sauver
User.find(1)                    # Lire par id
User.where(status: "active")    # Filtrer
User.find_by(email: "INPUT")    # Premier match
User.update(1, first_name: "X") # Mettre à jour
User.find(1).destroy            # Supprimer
```
