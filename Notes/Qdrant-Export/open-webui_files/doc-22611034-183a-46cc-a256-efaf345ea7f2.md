# Fiche Mémo — Ruby — Sauvegarde de données (JSON, CSV, Google Spreadsheet)

### 🚀 Setup rapide
- Créer un dossier Ruby structuré (`lib/`, `db/`, `spec/`, etc.).
- Initialiser Bundler et les gems utiles.
- Préparer les classes POO : `Scrapper`, `Saver`, `SpreadsheetClient`.
- Gérer les secrets via `.env` et variables d'environnement.

```bash
ruby -v && bundler -v
bundle init
bundle add dotenv json google_drive csv rspec
rspec --init
```

### 📦 Commandes clés
- Installer les dépendances.
- Lancer l'app.
- Exécuter les tests.
