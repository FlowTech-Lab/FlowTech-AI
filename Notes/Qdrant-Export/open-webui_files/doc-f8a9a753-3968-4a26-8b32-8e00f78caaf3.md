# Fiche Mémo — Rails — Petits sites de BDD relationnelles

### 🚀 Setup rapide
- Installer Ruby et Rails à la version du projet.
- Créer l'app: `rails new app_rel_db -T -d postgresql` puis configurer `database.yml`.
- Générer les models et migrations pour `Doctor/Patient/Appointment`, `Dogsitter/Dog/Stroll`, `User/Gossip/Tag/...`.
- Ajouter `gem 'faker'` pour le seed.
- Exécuter: `rails db:create db:migrate db:seed`.
- Utiliser `rails console` pour valider les relations.
- Préparer un README minimal et un schéma ERD léger si utile.

### 📦 Commandes clés
```bash
rails g model Entity name:string status:string
rails g migration AddReferenceToItems entity:references
rails db:create db:migrate db:seed
rails console
rails routes
rubocop -A
```
