# Fiche Mémo — Ruby — Boucles & Exercices

### 🚀 Setup rapide
- Installer Ruby et Bundler.
- Initialiser un repo et un dossier `lib/`.
- Fichiers attendus: `00_hello.rb`, `01_pyramids.rb`, `02_password.rb`, `03_stairway.rb`.
- Lancer chaque fichier avec `ruby lib/FILE.rb`.
- Ajouter des méthodes `perform` pour l'entrée unique.

### 📦 Commandes clés
```bash
ruby lib/00_hello.rb
ruby lib/01_pyramids.rb
ruby lib/02_password.rb
ruby lib/03_stairway.rb
git init && git add . && git commit -m "init"
```
