### ⚙️ Build / Run / Deploy
- CI minimale avec cache bundler et exécution `rspec`.
```yaml
# .github/workflows/ci.yml (exemple)
name: ci
on: [push, pull_request]
jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: ruby/setup-ruby@v1
        with: { ruby-version: '3.3' }
      - run: bundle install --path vendor/bundle
      - run: bundle exec rspec --format progress
```
- Option: générer un rapport de couverture.
```rb
# spec/spec_helper.rb
require "simplecov"; SimpleCov.start
```

### 🚫 Pièges & bonnes pratiques
- Éviter les espaces dans les chemins de projet. Préférer `_`.
- Un test = un comportement. Noms clairs. Données d'INPUT minimales.
- Isoler les I/O réseau. Mock/stub des dépendances lentes.
- Rendre les tests déterministes. Pas d'horloge réelle sans contrôle.
- Faites échouer vite et verbeux (`--fail-fast` quand pertinent).
