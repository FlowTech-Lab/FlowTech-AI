### 🔗 Relations / Composition
- [[Service]] Cache persiste ses entrées via ActiveRecord; nettoyable par rake/cron.
- [[Service]] Queue stocke, verrouille et exécute des jobs via `job:work`.
- [[Service]] Cable diffuse via `ActionCable.server.broadcast` et s'appuie sur la même DB.
- Les trois services partagent `[[Config]]` et la base `sqlite3` ou autre `[[Component]] DB`.

### 🧪 Test / Validation
```bash
# Cache
bin/rails c <<<'Rails.cache.write("k","v",expires_in:60); puts Rails.cache.read("k")'
# Queue
bin/rails c <<<'TestJob.perform_later("ok")'
bin/rails job:work --once
# Cable (sanity)
bin/rails routes | grep cable
```
```rb
# Expectation simple
raise "Cache KO" unless Rails.cache.fetch("k"){nil} == "v"
```
