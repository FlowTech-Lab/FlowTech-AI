### 🧪 Test / Validation
```bash
# Lancer test et linter génériques
bundle exec rspec
bundle exec rubocop
```

```rb
# Exemple RSpec minimal
RSpec.describe User, type: :model do
  it "requiert un email unique" do
    expect { User.create!(email: "INPUT") }.to change(User, :count).by(1)
    expect(User.new(email: "INPUT")).not_to be_valid
  end
end
```

### ⚙️ Build / Run / Deploy
- Dev: `rails s` ou via `foreman`/`overmind` pour plusieurs process.
- CI: appliquer `rails db:schema:load --trace` puis `rails db:migrate`.
- Prod: exécuter migrations lors du déploiement (`bin/rails db:migrate`).
- Sauvegarder `schema.rb` en VCS. Éviter d'éditer `schema.rb` à la main.
