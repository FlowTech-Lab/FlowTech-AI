### ⚙️ Build / Run / Deploy
- Exécution locale simple via `ruby`. Pas de build.
- Optionnel: créer `bin/run` pour lancer un exo choisi.
```bash
#!/usr/bin/env bash
ruby "lib/exo_${1}.rb"
# usage: ./bin/run 07
```

### 🚫 Pièges & bonnes pratiques
- Utiliser `gets.chomp` pour éviter le retour chariot.
- Caster en entier avec `to_i` avant les boucles numériques.
- Borner l'entrée utilisateur: `clamp(1,25)` pour les pyramides.
- Éviter les constantes magiques: factoriser dans `utils.rb`.
- Commits petits et fréquents.

### ✅ Checklist express
1. Un fichier par exo dans `lib/`.
2. Entrées correctement typées et bornées.
3. Aucune donnée privée, seulement `INPUT` ou exemples.
4. Repo GitHub propre avec README minimal et `.ruby-version`.
5. Lancer chaque exo au moins une fois et vérifier la sortie.
