# Fiche Mémo — Git & GitHub

### 🚀 Setup rapide
- Installer [[Service]] Git : `sudo apt install git` ou <package manager>.
- Configurer identité : 
  ```bash
  git config --global user.name "USERNAME"
  git config --global user.email "EMAIL"
  ```
- Activer clé SSH pour GitHub : générer puis ajouter la clé publique dans les réglages du compte.
