# Fiche Mémo — Ruby — Arrays & Hashes

### 🚀 Setup rapide
- Dossier minimal pour scripts et utilitaires.
```bash
mkdir app && cd app
bundle init && touch lib/app_arrays.rb lib/app_hashes.rb script_A.rb
```
- Exécuter un script Ruby.
```bash
ruby script_A.rb
```
- Ajouter outils qualité.
```bash
bundle add rspec rubocop
```

### 📦 Commandes clés
```bash
# Lancer
ruby lib/app_arrays.rb
# Linter auto-correct
rubocop -A
# Tests
rspec --format doc
```
