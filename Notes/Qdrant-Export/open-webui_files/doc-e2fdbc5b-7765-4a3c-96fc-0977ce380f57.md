# Fiche Mémo — Ruby on Rails

### 🚀 Setup rapide
- Pré‑requis: Ruby, Bundler, SQLite/PostgreSQL, Node/Yarn optionnels.
- Installer Rails : `gem install rails -v "<VERSION_THPSI_BLOQUEE>"`.
- Créer l'app : `rails new app_name` puis `cd app_name && bundle install`.
- Configurer DB dans `config/database.yml` si autre que SQLite.
- Initialiser repo Git et `.env` pour secrets génériques.
