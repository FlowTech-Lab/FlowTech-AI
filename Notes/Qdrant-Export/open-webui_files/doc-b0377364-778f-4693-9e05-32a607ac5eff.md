# Fiche Mémo — Ruby Automation & Terminal

### 🚀 Setup rapide
- Installer Ruby, Bundler, Git.  
- Ajouter la gem `launchy` pour ouvrir un navigateur.  
- Créer un dossier `tools/` pour scripts Ruby réutilisables.  
- Configurer un shell login et charger `~/.bash_profile` ou `~/.zshrc`.

### 📦 Commandes clés
```bash
ruby google_searcher.rb "how to center a div"
ruby mkdiruby.rb my_app
gem install launchy
rspec --init
```
- Alias recommandés dans le shell pour usage rapide.
