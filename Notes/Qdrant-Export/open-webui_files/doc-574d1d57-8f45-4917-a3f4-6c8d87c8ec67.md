# Fiche Mémo — Sinatra

### 🚀 Setup rapide
- Pré‑requis: Ruby ≥ 3.x, `bundler` installé.
- Init projet: `mkdir the_app && cd the_app && bundle init`.
- Gems minimales: `bundle add sinatra rerun csv`.
- Arbo MVC minimale: `lib/`, `lib/views/`, `db/`, `config.ru`, `Gemfile`.
- Fichier serveur: `lib/controller.rb` avec `ApplicationController < Sinatra::Base`.
- Base locale simple: `db/gossip.csv` ou JSON selon besoin.
- Lancer en dev: `rerun rackup -p 4567` pour rechargement auto.
