# Fiche Mémo — Rails — Models robustes

### 🚀 Setup rapide
- Pré-requis: Ruby, Rails, DB locale configurée.
- Créer app et model de test.
```bash
rails new app && cd app
rails g model User email:string
rails db:migrate
rails console
```
- Ajouter validations et méthodes dans `app/models/user.rb`.
- Configurer un mailer générique si besoin de callbacks d'e-mail.
