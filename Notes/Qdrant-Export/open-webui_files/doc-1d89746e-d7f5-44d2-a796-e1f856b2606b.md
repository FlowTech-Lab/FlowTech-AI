# Fiche Mémo — Ruby POO — mini jeu de combat

### 🚀 Setup rapide
- Pré-requis: Ruby ≥ 3.x, Bundler, `pry`.
- Init projet:
```bash
mkdir mini_jeu_POO && cd mini_jeu_POO
bundle init && echo "gem 'pry'" >> Gemfile && bundle
mkdir lib
touch app.rb app_2.rb app_3.rb lib/player.rb lib/game.rb README.md
```
- Entrée standard pour tests interactifs avec `binding.pry`.

### 📦 Commandes clés
- Lancer une version:
```bash
ruby app.rb    # v1 duel basique
ruby app_2.rb  # v2 menu interactif
ruby app_3.rb  # v3 avec classe Game
```
- Qualité code:
```bash
rubocop -A    # auto-correct safe
```
- Dépendances:
```bash
bundle install
```
