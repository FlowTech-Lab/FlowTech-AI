### 🚀 Setup rapide
- Installer Ruby ≥ 3.x et Bundler.
- Initialiser projet: `mkdir app && cd app && bundle init` puis éditer `Gemfile`.
- Gems minimales: `rspec`, `rubocop`, `pry` (optionnel).
- Init tests: `rspec --init` crée `spec/` et `.rspec`.
- Arbo type: `lib/`, `spec/`, `Gemfile`, `Gemfile.lock`, `.rubocop.yml`.
- Mettre `.rubocop.yml` "relaxed" si besoin.
- Tout le code en anglais, `snake_case`, indent 2 espaces.

### 📦 Commandes clés
```bash
bundle install                       # installe les gems du Gemfile
rspec                                # lance la suite de tests
rubocop                              # vérifie les conventions
ruby lib/script_A.rb                 # exécute un script
```
