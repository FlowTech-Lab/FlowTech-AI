### 📚 Glossaire mini
- **méthode** : fonction attachée à un objet/contexte Ruby.
- **bloc** : code entre `{}` ou `do…end`, passé implicitement.
- **yield** : exécute le bloc reçu par la méthode.
- **Proc** : objet encapsulant un bloc, appelé par `.call`.
- **lambda** : Proc stricte sur arité et `return` local.
- **arguments nommés** : paramètres `clé:` exigés à l'appel.
- **splat** `*args` : regroupe des arguments positionnels.
- **double splat** `**kwargs` : regroupe des arguments nommés.
- **pure** : méthode sans effets de bord pour une même entrée.
- **perform** : méthode orchestratrice qui séquence les appels.
