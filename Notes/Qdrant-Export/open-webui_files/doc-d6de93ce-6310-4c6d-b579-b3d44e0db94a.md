### 🔗 Relations / Composition
- [[Service]] "Queue" contient des [[Jobs]] gérés par Solid Queue.
- [[Component]] "Cable" utilise l'adaptateur base de données pour diffuser.
- [[Service]] "Cache" s'appuie sur Active Record via Solid Cache.
- Les trois s'imbriquent sans [[Service]] externe (pas de Redis).

### 🧪 Test / Validation
```bash
# Vérifier les migrations et la connexion
rails db:migrate:status
rails runner "puts ActiveRecord::Base.connection.active?"
# Tester un job en local
rails runner 'ExampleJob.perform_later("INPUT")'
```

### ⚙️ Build / Run / Deploy
- Déploiement simple: une base SQLite gérée par le système de fichiers.
- Sauvegardes: copier le fichier `.sqlite3` hors instance (snapshot + rotation).
- Démarrage: `rails server` ou serveur d'appli habituel (Puma).
- Jobs: `rails solid_queue:start` en service supervisé.
- Cable: config adapter `database` et processus web unique ou multiproc.
