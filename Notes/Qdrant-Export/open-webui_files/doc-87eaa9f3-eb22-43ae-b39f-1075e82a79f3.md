### 🚀 Setup rapide
- Créer app Rails avec SQLite:  
  ```bash
  rails new app --skip-javascript --database=sqlite3
  cd app && bin/setup
  ```
- Ajouter les models vides puis migrer:  
  ```bash
  rails g model User email:string phone_number:string description:text
  rails g model City name:string zip_code:string
  rails g model Listing available_beds:integer price:integer description:text has_wifi:boolean welcome_message:text user:references city:references
  rails g model Reservation start_date:datetime end_date:datetime user:references listing:references
  rails db:create db:migrate
  ```
- Ouvrir la console pour tester: `rails console`

### 📦 Commandes clés
```bash
rails g model Entity fields...
rails db:migrate
rails db:rollback STEP=1
rails db:reset   # drop+create+migrate+seed
rails console
bin/rspec        # si RSpec installé
```
