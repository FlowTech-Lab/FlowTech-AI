### 📚 Glossaire mini
- **MVC**: Modèle, Vue, Contrôleur.
- **ActiveRecord**: ORM de Rails pour manipuler la BDD.
- **Migration**: Script versionné qui modifie le schéma de BDD.
- **Seed**: Données initiales injectées via `db/seeds.rb`.
- **Generator**: Outil CLI pour créer fichiers standardisés.
- **Credentials**: Système chiffré pour secrets.
- **Hotwire**: Outils temps réel côté front optionnels.
- **Environment**: `development`, `test`, `production`.
