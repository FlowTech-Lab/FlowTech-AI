### 🔗 Relations / Composition
- "A contient B" : créer les parents avant les enfants.
- Utiliser `find_by!` pour lier précisément: récupérer un `User` puis créer ses `books`.
- Pour plusieurs modules de seed, charger dans l'ordre depuis `seeds.rb`:
```rb
%w[00_reset 10_users 20_books 30_links].each do |fname|
  load Rails.root.join("db/seeds", "#{fname}.rb")
end
```

### 🧪 Test / Validation
```bash
rails c
User.count                   # Vérifier le volume
User.last                    # Inspecter un enregistrement
rails db:seed VERBOSE=true   # Afficher les logs pendant le seed
```

### ⚙️ Build / Run / Deploy
- Dev: `rails db:seed` après `rails db:migrate`.
- CI: lancer `db:setup` dans un job dédié.
- Prod: activer un **seed minimal** idempotent et contrôlé par variables d'[[Environment]].
