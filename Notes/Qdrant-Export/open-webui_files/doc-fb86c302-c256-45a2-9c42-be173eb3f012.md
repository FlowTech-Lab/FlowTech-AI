# Fiche Mémo — SQL et bases de données relationnelles

### 🚀 Setup rapide
- Installer SQLite3.
```bash
# Ubuntu
sudo apt-get update && sudo apt-get install -y sqlite3 libsqlite3-dev
# macOS
brew install sqlite
```
- Créer une base locale et activer l'affichage lisible.
```bash
sqlite3 db.sqlite
.mode column
.headers on
```
- Sortir de l'interface : `Ctrl+D`.
