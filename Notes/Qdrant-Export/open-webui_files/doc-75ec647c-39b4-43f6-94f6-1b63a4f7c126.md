# Fiche Mémo — Rails Console

### 🚀 Setup rapide
- Avoir une app [[Module]] Rails initialisée et la BDD configurée.
- Lancer la console: `rails console` ou `rails c`.
- Mode sans effet persistant: `rails c --sandbox` pour annuler tous les changements à la sortie.
- Recharger le code après modifications: `reload!`.
- Optionnel: ajouter `table_print` dans le Gemfile pour un affichage tabulaire rapide.
