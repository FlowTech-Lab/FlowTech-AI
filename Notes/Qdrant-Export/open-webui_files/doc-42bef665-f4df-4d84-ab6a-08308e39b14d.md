# Fiche Mémo — Ruby

### 🚀 Setup rapide
- Installer Ruby via gestionnaire adapté (rbenv, asdf, ou package stable).
- Initialiser un projet: dossier `app/` avec `lib/`, `bin/`, `Gemfile`.
- Vérifier l'environnement et lancer l'IRB pour tester.
```bash
ruby -v
irb
gem install bundler
bundle init
```

### 📦 Commandes clés
- Vérifier gems et installer dépendances.
- Exécuter un script Ruby.
- Lancer un projet Rails minimal pour prototyper.
```bash
bundle install --path vendor/bundle
ruby script_A.rb
rails new app_demo --minimal
```
