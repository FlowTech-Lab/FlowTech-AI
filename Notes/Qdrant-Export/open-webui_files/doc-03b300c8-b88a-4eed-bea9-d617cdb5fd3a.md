# Fiche Mémo — Ruby

### 🚀 Setup rapide
- Installer [[Service]] Ruby ≥ 3.x via rbenv/rvm.
- Vérifier versions : `ruby -v` et `irb -v`.
- Démarrer IRB : `irb`; sortir : `quit`.
- Éditer avec [[Component]] éditeur, enregistrer en `.rb`.
