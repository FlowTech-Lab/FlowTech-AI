# Fiche Mémo — Ruby MVC — Terminal app avec CSV

### 🚀 Setup rapide
- Pré‑requis: Ruby ≥ 3.x, Bundler, Git.
- Init projet:
```bash
mkdir app_mvc && cd app_mvc
bundle init && echo "gem 'csv'" >> Gemfile && bundle
```
- Arborescence cible:
```
.
├── app.rb
├── Gemfile
├── db/gossip.csv
└── lib/{router,controller,view,entity}.rb
```

### 📦 Commandes clés
- Lancer l'app:
```bash
ruby app.rb
```
- Lint / style (exemple):
```bash
rubocop -A
```
- Tests (si présents):
```bash
rspec
```
