```

```

### ⚙️ Build / Run / Deploy
- Dev: `npx vite` avec HMR.
- Build: `npx vite build` génère `dist/`.
- CDN statique: GitHub Pages / Surge / Netlify. Utiliser chemins relatifs, assets minifiés.

### 🚫 Pièges & bonnes pratiques
- Ne pas multiplier les polices. Deux max.
- Un seul CTA primaire visible au-dessus de la ligne de flottaison.
- Contraste suffisant et tailles claires pour l'accessibilité.
- Mobile-first. Tester 360–1440 px.
- Réutiliser [[Component]] plutôt que copier-coller.
