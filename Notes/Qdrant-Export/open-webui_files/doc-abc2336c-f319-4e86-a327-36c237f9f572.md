### 🔗 Relations / Composition
- [[Module]] Routes dépend de [[Service]] Storage (CSV/JSON).
- [[Component]] Views consomme des objets [[Entity]].
- [[Config]] Rack charge `ApplicationController` et monte l'app.
- `params` sert de passerelle Front → Controller → Model.

### 🧪 Test / Validation

# linter/test minimal
bundle add rspec rubocop
rspec --init
# Exemple d'assertion simple
ruby -e "require './lib/gossip'; raise unless Gossip.all.is_a?(Array)"

### ⚙️ Build / Run / Deploy
- Dev: `rerun rackup -p 4567`.
- Prod simple: `RACK_ENV=production rackup -p 8080` derrière [[Service]] reverse proxy.
- Persistance locale: monter `db/` sur volume persistant.
- Logs: rediriger STDOUT/STDERR, activer `Rack::CommonLogger` si besoin.
