### ⚙️ Build / Run / Deploy
- Dev locale: `bin/rails s` puis http://localhost:3000
- Réinitialiser proprement: `bin/rails db:reset`
- Seed ciblé: `bin/rails db:seed:replant` (Rails 6.1+)

### 🚫 Pièges & bonnes pratiques
- Ne colle jamais de gros arrays bruts dans la fiche. Utilise `INPUT` ou `Faker`.
- Seeds idempotents: `delete_all` ou `find_or_create_by`, pas de doublons.
- Préfère une vraie FK `album_id` plutôt que stocker `album` en string.
- Vérifie `db:migrate:status` avant d'ouvrir la console.
- Évite les N+1, utilise `includes(:tracks)` pour les agrégats.
