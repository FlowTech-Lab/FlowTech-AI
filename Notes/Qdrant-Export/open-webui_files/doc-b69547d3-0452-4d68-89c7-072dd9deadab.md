### 📚 Glossaire mini
- **Route**: association verbe HTTP + chemin → bloc Ruby.
- **Params**: Hash request avec inputs GET/POST.
- **ERB**: templates HTML avec Ruby (`<% %>`, `<%= %>`).
- **Rack**: interface standard serveur Ruby.
- **Rackup**: lanceur de serveur Rack (`config.ru`).
- **Redirect**: réponse HTTP 3xx vers une route cible.
- **CSV Store**: persistance fichier tabulaire minimale.
- **MVC**: séparation Model / View / Controller.
