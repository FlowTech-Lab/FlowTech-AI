### ✅ Checklist express
1. RSpec installé et `rspec --init` exécuté.
2. Arborescence `lib/` et `spec/` propre, noms `*_spec.rb`.
3. Cas heureux + cas d'erreur testés.
4. Dépendances externes mockées.
5. CI exécute `rspec` sur chaque push.

### 📚 Glossaire mini
- **RSpec**: framework de tests pour Ruby basé sur des "specs" lisibles.
- **Minitest**: framework de test standard livrée avec Ruby.
- **TDD**: écrire les tests avant le code pour cadrer le besoin.
- **Fixture**: état de test partagé minimal, souvent via helpers.
- **Mock/Double**: objet simulé pour isoler une dépendance.
- **Stub**: réponse forcée d'une méthode pendant un test.
- **Spec Helper**: configuration commune chargée par les tests.
- **Coverage**: proportion de code exécutée par les tests.
