# Fiche Mémo — Rails 8 — Solid Cache, Solid Queue, Solid Cable

### 🚀 Setup rapide
- Prérequis: Ruby, Rails 8, SQLite3, bin/rails fonctionnel.
- Activer cache DB: `config.cache_store = :database` dans `[[Config]]` env prod.
- Générer tables système:
```bash
rails generate active_record:cache_migration
rails generate active_record:queue_migration
rails db:migrate
```
- Adapter Solid Cable à la base:
```yml
# config/cable.yml
production:
  adapter: sqlite3
  database: db/production.sqlite3
```
