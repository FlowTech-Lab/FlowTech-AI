### 🔗 Relations / Composition
- [[Config]] charge `.env` puis expose `ENV` aux [[Component]] CLI.
- [[Service]] OpenAI consomme `ENV["OPENAI_API_KEY"]` et retourne du texte.
- [[Module]] ChatSession combine historique `history` + `prompt` pour continuité.

### 🧪 Test / Validation

ruby -e 'require "http"; require "dotenv"; Dotenv.load; p HTTP.auth("Bearer #{ENV["OPENAI_API_KEY"]}").get("https://api.openai.com/v1/models").status.success?'
# linter rapide si présent

### ⚙️ Build / Run / Deploy
- Local: `ruby lib/app.rb` ou `bin/chatbot` exécutable.
- Env prod: limiter `max_tokens`, fixer `temperature`, journaliser les erreurs.
- CI: exécuter tests RSpec basiques + vérifs `.env` manquant.
