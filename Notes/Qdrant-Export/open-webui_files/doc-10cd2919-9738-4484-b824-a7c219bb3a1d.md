# Fiche Mémo — Ruby — Méthodes

### 🚀 Setup rapide
- Installer [[Module]] Ruby et un gestionnaire de versions si besoin.
- Vérifier la version : `ruby -v`.
- Lancer un bac à sable : `irb` pour tester des méthodes.
- Arbo générique : `lib/utils.rb`, `lib/app_arrays.rb`, `lib/app_hashes.rb`.
- Fichier d'entrée : `script_A.rb` qui appelle `perform`.

### 📦 Commandes clés
```bash
irb
ruby script_A.rb
bundle exec rspec
```
