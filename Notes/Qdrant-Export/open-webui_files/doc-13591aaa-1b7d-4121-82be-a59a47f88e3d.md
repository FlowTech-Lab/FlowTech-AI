# Fiche Mémo — Chatbot OpenAI en Ruby

### 🚀 Setup rapide
- Prérequis: Ruby ≥ 3.x, `bundler`, accès API OpenAI, terminal.
- Init projet:
```bash
mkdir chatbot_openai && cd chatbot_openai
bundle init
```
- Gemfile minimal:
```ruby
gem "http"
gem "json"
gem "dotenv"
gem "pry"
# gem "rspec" # optionnel
```
- Fichiers:
```
.env        # clés API (non commit)
.gitignore  # contient: .env
lib/        # code Ruby
spec/       # tests (si utilisés)
```
