### 🔗 Relations / Composition
- Router → Controller: dispatch des actions utilisateur.
- Controller ↔ Model(Entity): création, lecture, suppression.
- Controller → View: collecte des inputs et affichage.
- Model → CSV: persistance simple en fichier plat.

### 🧪 Test / Validation
```bash
# Exemple: vérifier persistance
ruby -e "require './lib/entity'; e=Entity.new('authorX','contentY'); e.save; puts Entity.all.size > 0"
```

### ⚙️ Build / Run / Deploy
- Exécution locale simple via `ruby app.rb`.
- Emballage CLI optionnel via `exe/` + gemspec si besoin.
- Persistance locale: `db/gossip.csv` créé à la volée.

### 🚫 Pièges & bonnes pratiques
- Valider les entrées utilisateur avant save.
- Ne pas surcharge I/O: ouvrir/fermer CSV proprement.
- Respecter "fat models, skinny controllers".
- Index utilisateur 1‑based, tableau 0‑based: ajuster.
- Gérer fichier absent ou vide.
