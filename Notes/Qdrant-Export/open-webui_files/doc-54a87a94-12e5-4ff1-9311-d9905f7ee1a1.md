# Fiche Mémo — Rails ActiveRecord Associations

### 🚀 Setup rapide
- Créer app de test:
```bash
rails new app_associations && cd app_associations
```
- Ajouter models avec attributs minimaux:
```bash
rails g model User first_name:string last_name:string city:string age:integer
rails g model Article title:string subject:string content:text user:references
```
- Migrer:
```bash
rails db:migrate
```

### 📦 Commandes clés
```bash
# créer un model
rails g model Entity name:string

# ajouter une FK après coup
rails g migration AddUserRefToArticles user:references
rails db:migrate
