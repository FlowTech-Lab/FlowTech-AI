# Fiche Mémo — Git & GitHub via SSH

### 🚀 Setup rapide
- Installer `git` et un client `ssh` sur [[Service]] local.
- Générer une paire de clés **sans** passphrase pour push rapide, ou **avec** passphrase + agent.
- Ajouter la clé publique au compte GitHub dans **SSH keys**.
- Configurer identité Git globale.
- Tester la connexion SSH à `github.com`.

### 📦 Commandes clés
```bash
# Générer une clé moderne (ed25519 recommandé)
ssh-keygen -t ed25519 -C "EMAIL"

# Variante RSA si besoin de compat
ssh-keygen -o -t rsa -b 4096 -C "EMAIL"

# Afficher la clé publique
cat ~/.ssh/id_ed25519.pub
