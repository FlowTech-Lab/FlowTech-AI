# Fiche Mémo — Testing en Ruby avec RSpec

### 🚀 Setup rapide
- Pré‑requis: Ruby ≥ 3.x, `gem` actif, dossier de projet propre.
- Installer RSpec globalement ou via Bundler.
```bash
gem install rspec
# ou dans un projet
bundle add rspec
rspec --init  # génère .rspec + spec/spec_helper.rb
```
- Arborescence conseillée:
```
project/
├── lib/                # code applicatif
├── spec/               # tests
│   └── spec_helper.rb
└── .rspec
```
