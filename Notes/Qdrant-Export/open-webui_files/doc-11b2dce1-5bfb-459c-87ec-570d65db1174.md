### 🔗 Relations / Composition
- `Application` instancie `Game` et contrôle la boucle de parties.
- `Game` orchestre `Board` et `Player`, gère le tour et le statut.
- `Board` gère `BoardCase` et la validation des coups.
- `Show` lit `Board` et affiche l'état courant.
- Modules optionnels: `Input` pour parser, `Rules` pour extensions 4x4.

### 🧪 Test / Validation
```bash
# Init tests
bundle exec rspec --init
```
```rb
# spec/board_spec.rb — assertion minimale
RSpec.describe Board do
  it "detects a horizontal win" do
    b = Board.new; %w[A1 A2 A3].each { |p| b.play!(p, "X") }
    expect(b.winner).to eq("X")
  end
end
```

### ⚙️ Build / Run / Deploy
- Lancer local: `ruby app.rb`.
- Script makefile optionnel:
```bash
run:; ruby app.rb
test:; bundle exec rspec
lint:; rubocop
```
- CI basique: exécuter `bundle install`, `rubocop`, `rspec` sur chaque push.
