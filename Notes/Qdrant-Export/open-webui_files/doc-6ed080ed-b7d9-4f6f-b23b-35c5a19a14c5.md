# Fiche Mémo — Front-end — Bootstrap & Sites statiques

### 🚀 Setup rapide
- Créer l'arbo générique du projet.
```bash
mkdir site && cd site
mkdir assets css img js
touch index.html css/styles.css js/app.js
```
- Ajouter Bootstrap et Font Awesome via CDN dans `<head>` et avant `</body>`.
- Approche **mobile-first**. Tester en mode responsive du navigateur.

### 📦 Commandes clés
```bash
# Servir localement
python3 -m http.server 8080

# Minifier CSS/JS (exemple générique avec esbuild)
npx esbuild js/app.js --bundle --minify --outfile=dist/app.min.js
```
