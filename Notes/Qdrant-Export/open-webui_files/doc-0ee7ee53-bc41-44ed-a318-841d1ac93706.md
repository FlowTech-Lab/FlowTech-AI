### 🔗 Relations / Composition
- Local ↔ [[Service]] Remote via `origin`.
- Branch contient des Commits. Remote suit des Branches distantes (`origin/main`).
- Stash contient des deltas temporaires liés à la Working Tree.
- Hooks dans `.git/hooks` orchestrent des actions (lint, tests) avant/after commit/push.

### 🧪 Test / Validation
```bash
# linter/test minimal, commandé ou assertion simple
git diff --name-only | xargs -r echo "Files changed:"
git fsck --full         # vérification intégrité
git status --porcelain  # sortie machine-friendly
```
```bash
# pré-commit simple (exemple)
echo -e '#!/bin/sh
set -e
rubocop || exit 1' > .git/hooks/pre-commit && chmod +x .git/hooks/pre-commit
```

### ⚙️ Build / Run / Deploy
- CI: exécuter tests sur chaque push (`main` protégé).
- Release: tag sémantique.
  ```bash
  git tag -a vX.Y.Z -m "release: vX.Y.Z"
  git push origin vX.Y.Z
  ```
- Déploiement: pipeline écoute tags ou branches protégées.
