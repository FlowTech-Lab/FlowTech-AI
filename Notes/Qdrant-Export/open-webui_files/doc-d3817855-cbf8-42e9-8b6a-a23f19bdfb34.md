# Fiche Mémo — Landing Page & Atomic Design

### 🚀 Setup rapide
- Créer un dossier projet et initialiser le versioning.
```bash
mkdir landing && cd landing
git init
```
- Ajouter Bootstrap via CDN ou npm.
```bash
npm init -y && npm i bootstrap
```
- Démarrer un serveur local simple.
```bash
npx live-server .
```

### 📦 Commandes clés
- Installer un thème Bootswatch rapide.
```bash
npm i bootswatch
```
- Builder les assets avec un bundler minimal.
```bash
npx vite build
```
- Déployer en statique.
```bash
npx surge ./dist <DOMAIN_OPTIONNEL>
```
