# Fiche Mémo — Rails — Models & Migrations

### 🚀 Setup rapide
- Pré‑requis: Ruby, Bundler, PostgreSQL ou SQLite, `rails` installé.
- Crée une app minimale: 
```bash
rails new app_name --database=postgresql
cd app_name && bin/setup
```
- Config DB dans `config/database.yml` si besoin.
- Initialise le dépôt git et un `.env` pour secrets de [[Config]].
