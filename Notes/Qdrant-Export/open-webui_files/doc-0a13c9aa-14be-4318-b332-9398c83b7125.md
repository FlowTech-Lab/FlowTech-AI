# Fiche Mémo — Arrays et boucles en Ruby

### 🚀 Setup rapide
- Avoir Ruby ≥ 3.x et `irb` disponibles.
- Ouvrir un shell interactif: `irb`.
- Alternative fichier: créer `script_A.rb`, exécuter `ruby script_A.rb`.

### 📦 Commandes clés
```bash
irb                 # shell interactif pour tester
ruby script_A.rb    # exécuter un fichier Ruby
rubocop .           # linter Ruby (optionnel)
rspec               # tests si présents
```
