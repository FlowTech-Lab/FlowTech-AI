### 📦 Commandes clés
```bash
rails g model User email:string is_admin:boolean   # crée model + migration
rails g migration AddIndexToUsersEmail             # migration vide
rails db:migrate                                   # applique migrations (up)
rails db:rollback                                  # annule la dernière (down)
rails db:migrate:status                            # tableau up/down
rails db:seed                                      # exécute db/seeds.rb
rails c                                            # console Rails
rails db:schema:load                               # charge schema.rb (reset)
rails db:reset                                     # drop + create + migrate + seed
```
