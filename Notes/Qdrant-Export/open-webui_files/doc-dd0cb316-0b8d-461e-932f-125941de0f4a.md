### ⚙️ Build / Run / Deploy
- Cloner via SSH, développer, valider (`git add/commit`), pousser.
- Pour CI/CD, injecter une **Deploy Key** ou **SSH key** dédiée par [[Service]] CI.
- Sur serveurs, utiliser `ssh-agent`/`ssh-add` ou variables protégées.

### 🚫 Pièges & bonnes pratiques
- Ne pas committer `~/.ssh/*` ni clés privées. Ignorer via `.gitignore`.
- Droits fichiers: `chmod 700 ~/.ssh` et `chmod 600 ~/.ssh/*`.
- Éviter multiples clés non documentées. Centraliser dans `~/.ssh/config`.
- Préférer **ed25519**. RSA 4096 seulement si contrainte.
- Si passphrase, activer un agent persistant (Keychain, Pageant, gnome-keyring).

### ✅ Checklist express
1. Générer clé `ed25519` et sécuriser droits.
2. Ajouter clé à l'agent.
3. Copier `id_ed25519.pub` dans **GitHub → SSH keys**.
4. `git config --global user.name/email`.
5. `ssh -T git@github.com` doit réussir.
6. Convertir remotes en SSH et tester `git push`.
