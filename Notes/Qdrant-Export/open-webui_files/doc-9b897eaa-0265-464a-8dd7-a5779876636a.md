### 📦 Commandes clés
- Initialiser un dépôt dans un dossier projet.
  ```bash
  git init
  ```
- Voir l'état courant.
  ```bash
  git status
  ```
- Ajouter des fichiers ciblés ou tout le dossier.
  ```bash
  git add FILE1 FILE2
  git add .
  ```
- Créer un commit atomique et descriptif.
  ```bash
  git commit -m "feat: MESSAGE"
  ```
- Inspecter les changements.
  ```bash
  git diff        # non indexés
  git diff --staged  # indexés
  ```
- Historique condensé.
  ```bash
  git log --oneline --graph --decorate --all
  ```
- Lier une remote et pousser.
  ```bash
  git remote add origin SSH_OR_HTTPS_URL
  git push -u origin main
  ```
- Récupérer et fusionner depuis la remote.
  ```bash
  git pull --ff-only origin main
  ```
