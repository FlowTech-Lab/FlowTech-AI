### ✅ Checklist express
1. Arborescence claire `lib/`, `spec/`, scripts séparés.
2. Méthodes pures avec entrées/sorties explicites.
3. Aucune fuite de données privées.
4. `rubocop` vert, `rspec` vert.
5. Rapports `report.json` et `report.csv` générés.

### 📚 Glossaire mini
- **Array**: liste ordonnée.
- **Hash**: table clé→valeur.
- **Enumerable**: mixin fournissant `map`, `select`, `tally`.
- **tally**: histogramme d'occurrences.
- **zip**: fusion élément par élément de listes.
- **sort_by**: tri par critère.
- **min_by/max_by**: extrêmes par critère.
- **Idempotent**: ré-exécution sans effet secondaire.
- **CLI**: interface ligne de commande.
- **Fixture**: jeu de données de test synthétique.
