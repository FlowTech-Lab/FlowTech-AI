### 🔗 Relations / Composition
- "Entity a plusieurs Item"; "Item appartient à Entity".
- `has_many :items, dependent: :nullify` côté [[Entity]].
- `belongs_to :entity, optional: true` côté [[Item]].
- Services applicatifs dans `app/services/` pour logique métier partagée.
- Jobs asynchrones dans `app/jobs/` si besoin.

### ⚙️ Build / Run / Deploy
- Lancer en dev: `bin/rails s` et `bin/rails db:prepare`.
- Tâches DB: `db:create db:migrate db:seed db:reset`.
- Variables d'env: config via `credentials` ou `ENV` dans `config/*.rb`.
- Déploiement: utiliser `release` task pour `db:migrate` + `assets:precompile` si front.
- Healthcheck: endpoint minimal dans un [[Controller]] générique.
