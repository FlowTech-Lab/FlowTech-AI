### ⚙️ Build / Run / Deploy
- Dev local: `bin/dev` si utilisé, sinon `rails s`.
- Reset propre: `rails db:reset` pour rejouer schéma et seed.
- Production SQLite: activer pool/timeout raisonnables et `config.cache_store = :database` si souhaité.  
- Migrer avant boot: `rails db:migrate RAILS_ENV=production`.
