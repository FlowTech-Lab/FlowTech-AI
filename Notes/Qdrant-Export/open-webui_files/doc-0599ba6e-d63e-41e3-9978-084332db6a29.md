### 📚 Glossaire mini
- **MVC**: séparation Model/View/Controller.
- **Router**: aiguillage des actions utilisateur.
- **Controller**: orchestration I/O ↔ persistance.
- **Model**: logique métier + accès données.
- **View**: interface terminal (puts/gets).
- **CRUD**: Create Read Update Delete.
- **CSV**: format texte à valeurs séparées par virgule.
- **Persistence**: sauvegarde sur disque.
- **Idempotent**: même entrée ⇒ même état.
- **I/O**: entrées/sorties (terminal, fichier).
