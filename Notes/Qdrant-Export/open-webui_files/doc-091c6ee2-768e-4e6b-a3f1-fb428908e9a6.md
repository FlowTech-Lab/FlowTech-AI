### 🔗 Relations / Composition
- Un [[Module]] regroupe des méthodes partagées et peut être inclus dans plusieurs [[Component]].
- Une [[Service]] consomme des [[Config]] et orchestre des [[Module]].
- Les scripts Ruby importent via `require_relative "lib/app_utils"` pour composer.

### 🧪 Test / Validation
```bash
# Lancer un test minimal si RSpec est installé
rspec --format documentation
# Vérifier syntaxe
ruby -c script_A.rb
```

### ⚙️ Build / Run / Deploy
- Run local: `ruby script_A.rb`.
- Packager une CLI: structure `bin/` + `lib/` et shebang `#!/usr/bin/env ruby`.
- Déployer comme gem: `gem build`, `gem install` (hors scope débutant).
