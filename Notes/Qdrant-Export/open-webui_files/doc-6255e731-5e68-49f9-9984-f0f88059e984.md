def no_conflict
    return unless start_date && end_date && listing
    if listing.overlapping_interval?(start_date, end_date)
      errors.add(:base, "dates overlap an existing reservation")
    end
  end
end

### 🔗 Relations / Composition
- Un User administre plusieurs Listing; un Listing appartient à un User.  
- Un Listing appartient à une City; une City agrège plusieurs Listing.  
- Une Reservation lie un User (guest) à un Listing pour un intervalle.  
- Vue système: [[Module]] Booking utilise [[Service]] Payment et [[Component]] Availability sur Listing.
