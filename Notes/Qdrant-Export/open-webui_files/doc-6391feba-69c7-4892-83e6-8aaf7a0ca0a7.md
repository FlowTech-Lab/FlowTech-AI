## 📋 Template Fields

### VM Template
- `type`: vm
- `name`: Machine name
- `ip`: IP address
- `ram_gib`: RAM in GB
- `cpu`: Number of CPUs
- `status`: active/inactive/maintenance
- `services`: List of running services
