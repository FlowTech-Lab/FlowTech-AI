### 🚫 Pièges & bonnes pratiques
- Ne jamais commiter `.env`; ajouter au `.gitignore`.
- Gérer les erreurs HTTP et les réponses vides (`choices[0]` peut être nil).
- Limiter `max_tokens` et `n` pour maîtriser coût et latence.
- Sauver un historique court pour éviter le dépassement de contexte.

### ✅ Checklist express
1. Gems installées et `.env` présent.
2. Appel API minimal qui retourne du texte.
3. CLI qui boucle jusqu'à `stop`.
4. Historique de conversation compact.
5. README avec usage et limites.

### 📚 Glossaire mini
- **API**: interface pour appeler un service logiciel.
- **Token**: unité de texte facturée et limitée.
- **Prompt**: texte d'entrée qui guide la génération.
- **Temperature**: contrôle de variabilité de sortie.
- **ENV**: variables d'environnement accessibles dans Ruby.
- **Pry**: REPL de debugging en pause dans l'exécution.
- **HTTP gem**: client Ruby pour requêtes web.
- **Completions**: endpoint textuel simple d'OpenAI.
