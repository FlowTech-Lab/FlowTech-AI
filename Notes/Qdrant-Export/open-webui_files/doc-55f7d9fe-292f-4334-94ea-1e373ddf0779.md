### ⚙️ Build / Run / Deploy
- Dev local: `rails s` puis vérifier les models via la console.
- DB: PostgreSQL conseillé; ajouter variables d'environnement dans `config/database.yml`.
- Déploiement: préparer `DATABASE_URL` et exécuter `rails db:migrate` sur l'environnement cible.
- Lint: `rubocop -A` et `rails db:schema:dump` pour versionner le schéma.

### 🚫 Pièges & bonnes pratiques
- Ne pas appeler `.last_name` directement sur un `Array`; indexer d'abord un élément.
- Toujours indexer les FK et ajouter `null: false` quand pertinent.
- Seed idempotent: nettoyer ou `find_or_create_by` pour éviter les doublons.
- Utiliser models de jointure nommés pour ajouter des métadonnées si besoin.
- Éviter la logique métier dans les seeds.
