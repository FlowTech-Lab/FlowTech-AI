### 🔗 Relations / Composition
- Un [[Service]] orchestre des [[Module]]s et manipule des [[Entity]].
- Les [[Component]] consomment des [[Config]] et exposent des méthodes publiques.
- Préférer l'injection de dépendances à l'accès global.

### ⚙️ Build / Run / Deploy
- Exécuter localement avec `ruby` ou via un binaire `bin/run` exécutable.
- Gérer les gems avec Bundler et verrouiller `Gemfile.lock`.
- Pour le web, démarrer un serveur Rack/Rails avec variables d'environnement sûres.
```bash
chmod +x bin/run && ./bin/run
bundle exec rackup
bundle exec rails server
```
