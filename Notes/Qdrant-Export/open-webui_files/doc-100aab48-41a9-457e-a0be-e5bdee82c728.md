```bash
# Objectif: corriger un remote mal pointé
git remote set-url --add --push origin git@github.com:ORG_OR_USER/REPO.git
git remote set-url --delete --push origin https://github.com/ORG_OR_USER/REPO.git
```
### 🔗 Relations / Composition
- **Keypair** alimente **Agent** qui signe les requêtes SSH.
- **KnownHosts** stocke l'empreinte de `github.com`.
- **Config** Git référence **user.name** et **user.email**.
- **Remote** du **Repo** utilise le protocole SSH pour `push/pull`.

### 🧪 Test / Validation
```bash
# 1) Clé chargée ?
ssh-add -l

# 2) Connexion GitHub OK ?
ssh -T git@github.com  # doit renvoyer un message "successfully authenticated"

# 3) Droits SSH sécurisés ?
ls -l ~/.ssh           # fichiers privés en 600, dossier en 700

# 4) Remote cohérent ?
git -C PATH/TO/REPO remote -v | grep git@github.com
```
