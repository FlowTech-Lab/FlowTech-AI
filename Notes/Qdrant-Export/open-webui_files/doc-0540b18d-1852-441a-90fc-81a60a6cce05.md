### 📦 Commandes clés
- Initialiser migrations Solid: 
```bash
rails generate active_record:cache_migration && rails generate active_record:queue_migration
```
- Migrer la base: 
```bash
rails db:migrate
```
- Lancer le worker de jobs: 
```bash
bin/rails job:work
```
- Vérifier cache en console: 
```bash
bin/rails console
```
