# Fiche Mémo — Ruby POO — Morpion

### 🚀 Setup rapide
- Prérequis: Ruby ≥ 3.x, Bundler, Git.
- Init projet:
```bash
git init && bundle init
bundle add rspec rubocop colorize
mkdir -p lib spec
```
- Fichiers d'entrée: `app.rb` (lance le jeu), 1 classe par fichier dans `lib/`.
- Convention: POO stricte, aucune persistance (pas de CSV/JSON).
- Terminal only: entrée via `gets.chomp`, affichage stylé ASCII.
