# Fiche Mémo — HTML & CSS — Première page web

### 🚀 Setup rapide
- Créer la structure minimale.
```bash
mkdir site && cd site
mkdir assets css
touch index.html css/style.css
```
- Ouvrir dans l'éditeur et lancer un serveur local simple.
```bash
# avec Python
python -m http.server 8000
```

### 📦 Commandes clés
```bash
# valider HTML/CSS en ligne (validator)
# lancer un serveur local alternatif
npx serve .
# minifier CSS (exemple générique)
npx csso css/style.css -o css/style.min.css
```
