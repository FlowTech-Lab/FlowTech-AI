```rb
# Accumuler un résultat via each
sum = 0
prices.each { |p| sum += p }
puts sum
```

```rb
# Boucle while avec condition d'arrêt
i = 1
while i <= 5
  puts i
  i += 1
end
```

```rb
# Lecture utilisateur avec arrêt conditionnel
input = ""
while input != "OK"
  puts "Tape OK:"
  input = gets.chomp
end
puts "Merci"
```

### 🔗 Relations / Composition
- `times` répète N fois un bloc.
- `for .. in` ou `(1..n).each` itèrent sur un Range.
- `each` consomme séquentiellement les éléments d'un `Array`.
- `map` produit un **nouvel** `Array`; `map!` modifie **en place**.
- `while` boucle tant que la condition reste `true`.
